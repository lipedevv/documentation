# 检查服务器健康

运行 `/doctor status` 或打开仪表板. 查看显示的健康状况,以及玩家报告,当前性能,内存使用和开放事件.

较低的分数意味着服务器需要注意;它本身不识别有错误的插件.

如果需要更多细节,请查看控制台,并使用服务器的支持性能工具.

对于一个活跃的问题, 关注 [调查事件](incident-investigation.md).
