# 调查问题

1. 确认玩家正在经历什么,并注意它是什么时候开始的.
2. 运行 `/doctor status` 和 `/doctor incidents`.
3. 打开仪表板上事件,阅读可用的详细信息和建议检查.
4. 时间与最近的变化 [recent changes](../changes/change-tracker.md)相比较.
5. 阅读相关控制台错误并检查受影响插件的文件.
6. 在更换服务器之前保存 [报告](../reports/creating-reports.md) .
7. 退出,做一个可逆的改变,

{% hint style="warning" %}
处理一个可疑的插件和任何信任指标作为调查指南,而不是保证.
{% endhint %}
