# 保存诊断快照

运行 `/doctor snapshot`. 命令报告生成的文件的路径在 `plugins/MRKDoctor/snapshots/`中 .

在调查问题或更改插件配置之前,请随时记录一张快照.

{% hint style="warning" %}
快照是一个诊断记录,而不是服务器备份.它不能恢复世界,插件文件,配置或完整的MRK Doctor数据文件.保持单独的备份.
{% endhint %}
