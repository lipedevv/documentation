# 仪表板

仪表板可以让你查看服务器健康,事件,变化和其他在版面上可用的诊断信息.

完整的仪表板嵌入了插件 JAR ,并从配置的仪表板端口服务.不需要单独的 Node.js 或 Next.js 托管. 在托管面板中选择可用的分配,并遵循 [初始设置](initial-setup.md).

限制可信任管理员的访问.不要在截图或公众支持消息中放出仪表板凭证.

如果页面打开,但没有连接,请按照 [解决问题](../support/troubleshooting.md#dashboard-will-not-connect).
