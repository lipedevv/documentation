# 检查权限和命令

目标玩家必须在线.

```text
/doctor permission Steve essentials.warp
/doctor command Steve warp
```

首先检查指定的权限.第二个命令帮助识别命令的插件和检查访问.只提供命令名称,没有额外的参数.

如果访问仍然失败,请检查命令的语法,权限组配置,世界限制和冷却.MRK Doctor不会更改玩家的权限或取代您的权限管理器.

这些检查可用于使用 `mrkdoctor.view`的用户,所以只向可信的员工提供该节点.
