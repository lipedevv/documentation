# 欢迎您

MRK 医生帮助服务器管理员调查延迟,插件错误和意想不到的变化.

您可以查看服务器健康状况,检查事件,查看最近的变化,查看播放器权限,并生成诊断报告.仪表板提供了网页接口来查看您的版本中可用的信息.

开始 [安装](installation.md),然后遵循 [快速启动](quick-start.md).

{% hint style="info" %}
由于MRK医生不会自动修复或倒挂您的服务器.
{% endhint %}
