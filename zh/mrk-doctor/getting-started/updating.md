# 更新

1. 备份服务器和完整的 `plugins/MRKDoctor/` 文件.
2. 停止服务器正常.
3. 取代旧JAR,用新版本的版本.
4. 查看发布说明,并将提供的配置与现有设置进行比较.
5. 启动服务器,检查 `/doctor status`,仪表板和控制台.

{% hint style="warning" %}
诊断快照不是备份.不要假设缺失配置选项将自动添加到现有文件中.
{% endhint %}
