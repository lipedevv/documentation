# 要求

环球版针对从Minecraft **1.8.9到 26.2**的Bukkit兼容服务器.使用服务器软件所需的Java版本.保持服务器和Java安装由各自的供应商支持.

优化版是 **Paper 1.21.x与Java 21**的单独构建.它不是传统服务器或纸 26.2的构建.

{% hint style="warning" %}
永远不要把万能版和优化版一起安装,或者保护和无保护的副本.
{% endhint %}

没有额外的插件是强制性的. 给诊断历史和出口报告留下足够的空格.

一些测量可能不在每个服务器版本上可用.一个不可用的测量并不意味着服务器健康或破产.

网络仪表板嵌入插件JAR.远程访问需要一个合适的托管配置和一个安全的网络地址或反转代理. 参见 [仪表板设置](../dashboard/initial-setup.md).
