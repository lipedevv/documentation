<a id="installation"></a>
# 装备

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### 选择您的文件
使用通用JAR,除非你特别需要优化的纸版. 保护和不保护的JAR是相同版本的替代版本.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### 停下来,退后
在添加插件之前,请正常停止Minecraft服务器并进行备份.
{% endstep %}
{% step %}
<a id="install"></a>
#### 安装
放一个MRK医生JAR在服务器的 `plugins/` 文件中.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### 开始检查
启动服务器. 确认没有MRK Doctor启动错误,然后将 `/doctor status` 作为操作员或从控制台运行. 允许时间进行初步测量.
{% endstep %}
{% endstepper %}

继续使用 [快速启动](quick-start.md).不要使用插件热装机安装或更换MRK Doctor.
