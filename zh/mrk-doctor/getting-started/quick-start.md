# 快速开始

1. 运行 `/doctor status` ,以检查当前服务器状态.
2. 在游戏中,运行 `/doctor` ,打开概况.
3. 运行 `/doctor incidents` 查看开放的问题.
4. 运行 `/doctor changes` ,查看最近的跟踪变化.
5. 需要支持报告时使用 `/doctor report` .

启动后,可能需要一些时间来进行第一次读取.

为了访问网页,请遵循 [仪表板设置](../dashboard/initial-setup.md). 如果已经影响玩家的问题,请打开 [解决问题](../support/troubleshooting.md).
