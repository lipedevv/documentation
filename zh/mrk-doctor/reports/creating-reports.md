# 创建和分享报告

运行 `/doctor report` 作为运营商或员工成员使用 `mrkdoctor.report`. 等待完成消息,然后从 `plugins/MRKDoctor/reports/`打开报告文件 .

简单版也可以在浏览器中打开HTML报告. 优化版也可以生成一个JSON伴侣.

在分享之前:

1. 阅读完整报告,并删除与此无关的信息.
2. 查找凭证,私人地址,文件路径,播放器详细信息和敏感配置值.
3. 仅提供需要调查问题的信息.
4. 使用验证的支持目的地.

{% hint style="danger" %}
机动掩盖并不保证报道没有秘密.
{% endhint %}

Include your Minecraft version, MRK Doctor version, a short description, reproduction steps, and the time the problem occurred. See [support](../../support.md).
