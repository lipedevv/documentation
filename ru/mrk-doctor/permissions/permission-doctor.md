# Проверяйте разрешения и команды

Участник должен быть в сети.

```text
/doctor permission Steve essentials.warp
/doctor command Steve warp
```

Первая команда проверяет указанное разрешение. Вторая помогает определить плагин команды и проверить доступ.

Если доступ все еще не удается, пересмотрите синтаксис команды, конфигурацию группы разрешений, ограничения мира и отключения. MRK Doctor не меняет разрешения игрока или не заменяет менеджера разрешений.

Эти проверки доступны для пользователей с `mrkdoctor.view`, поэтому предоставьте этот узел только доверенному персоналу.
