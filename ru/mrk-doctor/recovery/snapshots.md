# Сохранить диагностический снимок

Запустить `/doctor snapshot`. Показание сообщает путь генерируемого файла в `plugins/MRKDoctor/snapshots/`.

Сохраняйте снимок при расследовании проблемы или перед изменением конфигурации плагина.

{% hint style="warning" %}
Сноп-снимка - это диагностический запись, а не резервный копий сервера. Она не может восстановить миры, файлы плагинов, конфигурацию или полную папку данных MRK Doctor. Сохраняйте отдельные резервные копии.
{% endhint %}
