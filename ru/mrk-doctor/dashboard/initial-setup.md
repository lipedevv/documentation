<a id="connect-the-dashboard"></a>
# Подключить панель

{% stepper %}
{% step %}
<a id="create-a-credential"></a>
#### Создать аккредитив
Запустить `/doctor dashboard setup` в качестве оператора, скопировать отображенный токен немедленно и сохранить его в безопасности.
{% endstep %}
{% step %}
<a id="configure-the-address"></a>
#### Настройка адреса
В `plugins/MRKDoctor/config.yml`устанавливается `doctor.dashboard.port` на выделенный порт. По умолчанию `0.0.0.0` bind слушается на выделении сервера; изменить его на `127.0.0.1` , когда обратный прокси на том же хостере должен быть единственным прямым клиентом.
{% endstep %}
{% step %}
<a id="open-the-embedded-dashboard"></a>
#### Откройте встроенную панель управления
Откройте `http://SERVER_ADDRESS:PORT` в браузере и введите токен.
{% endstep %}
{% step %}
<a id="restart-only-after-connection-setting-changes"></a>
#### Возобновить только после изменения настройки подключения
Новый созданный токен незамедлительно активируется. Возобновить сервер Minecraft только после изменения адреса связывания, порта или включенного состояния.
{% endstep %}
{% endstepper %}

{% hint style="danger" %}
Не оставляйте диагностический порт незащищенным в общественном интернете. Защищайте удаленный доступ с помощью надежного обратного прокси, TLS, и брандмауэра. Не рассматривайте настройки веб-оригина как замену аутентификации.
{% endhint %}

Создание другого токену незамедлительно заменяет аккредитацию. Обновляйте доверенные браузеры новым токеном. См. [Pterodactyl](pterodactyl.md) и [безопасность](security.md).
