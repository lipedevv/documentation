# Создание и обмен докладом

Запустить `/doctor report` в качестве оператора или члена персонала с `mrkdoctor.report`. Подожди сообщения завершения и открыть сообщенный файл из `plugins/MRKDoctor/reports/`.

Универсальное издание создает HTML-репортаж, который можно открыть в браузере.

Перед делом:

1. Прочитайте полный отчет и удалите не связанную с ним информацию.
2. Поищите удостоверения личности, частные адреса, пути файлов, данные о игроке и чувствительные значения конфигурации.
3. Поделитесь только информацией, необходимой для расследования данного вопроса.
4. Используйте проверенный пункт назначения.

{% hint style="danger" %}
Автоматическое маскирование не гарантирует, что в докладе нет секретов.
{% endhint %}

Include your Minecraft version, MRK Doctor version, a short description, reproduction steps, and the time the problem occurred. See [support](../../support.md).
