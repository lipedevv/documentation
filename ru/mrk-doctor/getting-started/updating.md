# Обновление

1. Запись сервера и полная папка `plugins/MRKDoctor/` .
2. Прекратите сервер обычно.
3. Заменить старый JAR новым выпуском того же издания.
4. Проверьте записки об освобождении и сравните поставленную конфигурацию с существующими настройками.
5. Запустите сервер и проверите `/doctor status`, панель управления и консоль.

{% hint style="warning" %}
Диагностический снимок не является резервным копированием. Не предполагайте, что отсутствующие параметры конфигурации будут автоматически добавлены к существующему файлу.
{% endhint %}
