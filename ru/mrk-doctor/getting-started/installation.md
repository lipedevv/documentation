<a id="installation"></a>
# Установка

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Выберите файл
Используйте универсальный JAR, если вам не требуется специально оптимизированное бумажное издание.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Остановись и отступи.
Перестаньте использовать сервер Minecraft и сделайте резервную копию, прежде чем добавить плагин.
{% endstep %}
{% step %}
<a id="install"></a>
#### Установка
Положите один MRK Doctor JAR в папку `plugins/` вашего сервера.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Начнём и проверь
Запустить сервер. Убедитесь, что нет ошибок в запусках MRK Doctor, затем запустить `/doctor status` как оператор или с консоли.
{% endstep %}
{% endstepper %}

Продолжайте с [быстрое запуск](quick-start.md). Не используйте плагин-горячие загрузчики для установки или замены MRK Doctor.
