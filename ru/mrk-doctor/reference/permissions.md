# Разрешения

Все разрешения MRK Doctor по умолчанию для операторов. `mrkdoctor.view` требуется для каждой команды, включая те, которые имеют дополнительное разрешение.

| Разрешение | Доступ |
| --- | --- |
| `mrkdoctor.view` | Просмотреть диагностику, перечислить инциденты и изменения, создать снимки и проверить разрешения/поручение. |
| `mrkdoctor.report` | Создать отчеты. |
| `mrkdoctor.dashboard` | Просмотреть подробности подключения к панели управления и заменить ее аккредитацию. |
| `mrkdoctor.admin` | Административный доступ, включая перезагрузку и вышеуказанные разрешения. |

{% hint style="warning" %}
Не предоставляйте диагностические разрешения обычным игрокам.
{% endhint %}

Резервированные узлы `mrkdoctor.trace`, `mrkdoctor.rollback`и `mrkdoctor.update` не отключают отслеживание, обратное обращение или автоматические обновления в этом релизе.
