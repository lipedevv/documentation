# Приказ

Все команды требуют `mrkdoctor.view`. Допускаются по умолчанию для операторов. См. разрешения [permissions](permissions.md) перед делегированием доступа.

| Командование | Использование | Дополнительное разрешение |
| --- | --- | --- |
| `/doctor` | Откройте обзор игры; покажите состояние в консоле. | — |
| `/doctor status` | Покажите текущую информацию о состоянии здоровья и времени работы. | — |
| `/doctor health` | Покажите то же самое резюме о здоровье. | — |
| `/doctor incidents` | Перечисли открытые инциденты. | — |
| `/doctor changes` | Покажите последние изменения. | — |
| `/doctor timeline` | Покажите список недавних изменений в Universal. | — |
| `/допуск врача <player> <node>` | Check an online player's permission. | — |
| `/показание врача <player> <command>` | Check a command's owner and access. | — |
| `/doctor snapshot` | Сохраните диагностический снимок. | — |
| `/doctor report` | Создать файл отчета. | `mrkdoctor.report` |
| `/doctor dashboard` | Показывать настройку встроенного адреса панели управления. | `mrkdoctor.dashboard` |
| `/doctor dashboard setup` | Создать и незамедлительно активировать новую учетную запись панели управления. | `mrkdoctor.dashboard` |
| `/doctor reload` | Перезагрузить значения конфигурации; некоторые изменения все еще требуют перезагрузки. | `mrkdoctor.admin` |

Используйте точные имена онлайн-игроков для проверки игроков. Адрес, напечатанный `/doctor dashboard` , использует конфигурированный адрес связывания; заменить `127.0.0.1` или `0.0.0.0` публичным именем хоста при удаленном его открытии.

Оптимизированное издание Paper также предлагает плагин `/doctor <plugin>` для резюме плагина.

`/doctor trace` показывает только уведомление о доступности в этом релизе; он не запускает отслеживание.
