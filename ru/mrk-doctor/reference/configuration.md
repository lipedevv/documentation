# Ссылка на конфигурацию

Эта справка охватывает `plugins/MRKDoctor/config.yml` в универсальном издании. Возобновить после редактирования, если вы не проверили поведение перезагрузки настройки.

| Настройка | По умолчанию | Цель |
| --- | --- | --- |
| `doctor.server-id` | `standalone` | Этикет используется для этого сервера. |
| `doctor.performance.healthy-sample-seconds` | `15` | Интервал наблюдения во время нормальной работы. |
| `doctor.performance.incident-sample-seconds` | `5` | Интервал наблюдения во время инцидента. |
| `doctor.changes.enabled` | `true` | Осуществлять мониторинг последних изменений. |
| `doctor.changes.interval-seconds` | `30` | Проверка перемен; используйте не менее 10 секунд. |
| `doctor.changes.max-file-bytes` | `1048576` | Ограничение размера для детального сравнения текстовых файлов. |
| `doctor.dashboard.enabled` | `true` | Включить подключение к панели управления. |
| `doctor.dashboard.bind` | `0.0.0.0` | Слушайте на распределение сервера. Используйте `127.0.0.1` , когда доступ должен пройти через обратный прокси того же хоста. |
| `doctor.dashboard.port` | `7854` | Единый порт, используемый встроенной панелью управления и ее аутентифицированным API. |
| `doctor.dashboard.cors-origin` | `http://127.0.0.1:7854` | Необходимость разрешения на происхождение для продвинутых прокси-развертываний; доступ с одновременным происхождением не требует отдельного адреса фронтэнда. |
| `doctor.dashboard.token-hash` | Пустое | Управляется `/doctor dashboard setup`; не редактируйте вручную. |
| `storage.raw-retention-hours` | `24` | Период хранения для детальной метрической истории. |
| `logging.debug` | `false` | Оставьте по умолчанию; он не позволяет дополнительную запись в этом релизе. |

Используйте положительные интервалы мониторинга и действительный порт панели управления.

{% hint style="warning" %}
Не вставляйте токен панели в примеры конфигурации.
{% endhint %}
