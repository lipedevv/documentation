# Просмотр последних изменений

Run `/doctor changes` or use the dashboard to review available plugin and configuration changes. `/doctor timeline` currently shows the same recent-change list in the Universal edition.

Сравните временные знаки с сообщенной проблемой. Изменение, происходящее вблизи инцидента, является полезным контекстом, но не доказывает, что оно вызвало проблему.

MRK Doctor не смотрит на каждый файл или заменяет внешнюю систему резервного копирования. Чтобы отменить изменение, остановить сервер и следовать процедуре восстановления, поддерживаемой поставщиком плагинов, используя свою собственную резервную копию.

Отслеживание изменений может быть включено или отключено в конфигурации [configuration](../configuration/overview.md).
