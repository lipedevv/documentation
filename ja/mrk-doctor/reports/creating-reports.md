# 報告書を作成し共有する

`/doctor report` を `mrkdoctor.report`で操作員またはスタッフとして実行します.完了メッセージを待って, `plugins/MRKDoctor/reports/`から報告されたファイルを開きます.

ユニバーサル版はブラウザで開けるHTMLレポートを作成します.最適化されたペーパー版はJSONの伴侶も生成します.

共有する前に:

1. 報告書を全読して関連のない情報を削除します
2. 認証情報,プライベートアドレス,ファイル経路,プレイヤー詳細,そして敏感な設定値を探してください.
3. 問題を調査するために必要な情報のみを共有してください.
4. 確認されたサポート目的地を使用する

{% hint style="danger" %}
自動マスクは 報告に秘密が隠されていることを保証しません 常に自分で確認してください
{% endhint %}

Minecraft版,MRK Doctor版,簡略説明,再生手順,および問題が発生した時間を含む. [サポート](../../support.md)を参照.
