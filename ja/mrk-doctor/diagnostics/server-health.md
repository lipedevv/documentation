# サーバーの健康を確認

`/doctor status` を実行するか,ダッシュボードを開く.プレーヤーレポート,現在のパフォーマンス,メモリ使用,開いた事件とともに表示された健康状態をレビューする.

低点点点では,サーバーが注意を要するので,その上で有罪なプラグインを特定することはできません. 一瞬から結論を出すのではなく,時間の経過とともに読み方を比較してください.

古いサーバーバージョンでは,測定値が利用できない.コンソールを確認し,詳細が必要であればサーバーのサポートされたパフォーマンスツールを使用してください.

For an active problem, follow [investigate an incident](incident-investigation.md).
