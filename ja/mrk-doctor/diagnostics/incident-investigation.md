# 問題 を 調べる

1. 選手が経験していることを確認し 開始した時のことを確認する
2. `/doctor status` と `/doctor incidents`を実行する
3. 事件をダッシュボードに開いて 詳細とチェックの提案を読んでください
4. タイミングと [最近の変更を比較する](../changes/change-tracker.md)
5. 関連コンソールエラーを読み,影響を受けたプラグインのドキュメントを確認します.
6. サーバーを変更する前に [報告書](../reports/creating-reports.md) を保存する.
7. 逆転できる変化を 繰り返して 結果を観察する

{% hint style="warning" %}
疑わしいプラグインと信頼性を示すものすべてを調査ガイドとして扱ってください.保証ではありません.MRK医師は,修理やプラグイン更新,またはロールバックをあなたのために行いません.
{% endhint %}
