<a id="installation"></a>
# 設置

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### ファイルを選択
保護されたJARと保護されていないJARは,同じ版の代替バージョンである.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### 止まって後ろを
プラグインを追加する前に Minecraft サーバーを正常に停止してバックアップしてください.
{% endstep %}
{% step %}
<a id="install"></a>
#### インストール
サーバの `plugins/` フォルダーに MRK Doctor JARを入れて そのフォルダーから古いコピーを取り除く
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### 開始してチェック
サーバを起動します.MRK Doctorの起動エラーがないことを確認し,操作者として `/doctor status` を実行します.またはコンソールから実行します.初期測定に時間を与えます.
{% endstep %}
{% endstepper %}

[速 start](quick-start.md)を使用する.MRK Doctor をインストールまたは交換するためにプラグインホットロードを使用しないでください.
