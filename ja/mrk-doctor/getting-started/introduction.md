# 歓迎する

MRK Doctor はサーバー管理者が遅延,プラグインエラー,予期せぬ変更を調査するのを助けます.

サーバーの健康状態,インシデントの確認,最近の変更,プレイヤー許可を確認,診断レポートを作成できます.ダッシュボードは,編集中の情報を見直すためのウェブインターフェースを提供します.

[のインストールから始め](installation.md)を [の速 start](quick-start.md)をフォローします

{% hint style="info" %}
疑わしい原因は,プラグインが間違っている証拠ではなく,調査の手がかりです.MRK医師は自動的にサーバーを修復したり,リロールしたりしません.
{% endhint %}
