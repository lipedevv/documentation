# 早くスタート

1. `/doctor status` を実行して,現在のサーバー状態を確認します.
2. ゲームでは `/doctor` を実行して概要を開きます.
3. `/doctor incidents` を実行して,開いた問題を確認します.
4. 最近の変更を確認するために `/doctor changes` を実行します.
5. サポートレポートが必要な場合は `/doctor report` を使用してください.

起動後最初の読み取りは少し時間がかかるかもしれません. 新しいインストールを判断する前にサーバーを実行してください.

For web access, follow [dashboard setup](../dashboard/initial-setup.md). For a problem already affecting players, open [troubleshooting](../support/troubleshooting.md).
