# 要求

ユニバーサル版は,Minecraft **1.8.9 から 26.2**のBukkit対応のサーバーを対象としています.サーバーソフトウェアが要求するJavaバージョンを使用してください.サーバーとJavaインストールをそれぞれのベンダーがサポートしています.

優化されたペーパー版は,Java 21**と **Paper 1.21.x の別バージョンである.これは,レガシーサーバーやPaper 26.2 の別バージョンではありません.

{% hint style="warning" %}
ユニバーサルと最適化された紙版を一緒にインストールしたり,保護されたコピーと保護されていないコピーの両方をインストールしないでください.
{% endhint %}

追加プラグインは必須ではありません.診断履歴と輸出報告のために十分なディスクスペースを残します.

サーバーバージョンの各には測定が利用できない場合もあります.利用できない測定は,サーバーが健康または壊れていることを意味しません.

WebダッシュボードはJARプラグインに組み込まれています.リモートアクセスには適切なホスト配置と安全な Webアドレスまたはリバースプロキシが必要です. [ダッシュボード設定](../dashboard/initial-setup.md)を参照してください.
