# Pterodactyl ホスト

サーバーパネルで利用可能な割り当てを選択し,例えば `7854`を選択し,そのポートに `doctor.dashboard.port` を設定します.別々のウェブアプリケーションまたは第二の割り当ては必要ありません.

ホストネットワークが要求するバインドアドレスを使用します.コンテナのローカルホストアドレスは別々のコンテナからアクセスできません.ホストが `0.0.0.0`を要求する場合,アクセスを有効にする前に,そのファイアウォールまたはセキュアプロキシによって割り当てが保護されていることを確認してください.

ウェブダッシュボードはプラグインによって直接提供されます. [初期設定](initial-setup.md)を実行して,bindアドレスまたはポートを変更した後を再起動し,割り当てられたアドレスを使用してページをテストします.

{% hint style="warning" %}
接続問題を解決するために,制限のないポートを開くことはしないでください.あなたのプランでは割り当てを選択したり,露出したりできなければ,入入ダッシュボードポートをホストプロバイダのみがアクセスできるようにします.プラグインはホストファイアウォールを回避することはできません.
{% endhint %}
