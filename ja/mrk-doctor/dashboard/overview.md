# ダイッシュボード

機種が 機能する 機種が 機能する 機種が 機能する 機種が 機能する

完全ダッシュボードは JAR プラグインに組み込まれ,設定されたダッシュボードポートから提供されます.別々の Node.js または Next.js ホストは必要ありません. ホストパネルで利用可能な割り当てを選択し, [初期設定](initial-setup.md)を実行します.

信頼される管理者にアクセス制限を 保持する.スクリーンショットや公開サポートメッセージにダッシュボードの認証を 置かないこと.

ページが開いたが接続されていない場合は, [をフォローして,](../support/troubleshooting.md#dashboard-will-not-connect)をトラブルシューティングします.
