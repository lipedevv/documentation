# 支援

Start with [troubleshooting](mrk-doctor/support/troubleshooting.md). If you need help, prepare:

- Minecraft/サーバーソフトウェアバージョンとJavaバージョン
- MRK博士版と版
- 何が起こったのか いつ起きたのか どのようにして再現するか
- 関連コンソールエラーと 診断報告をレビューした

ダッシュボードトークン,パスワード,完全なプライベート設定ファイル,または関係のないプレイヤー情報を送信しないでください.

公式のサポートリンクはまだ提供されていません.購入に関連した確認されたサポート目的地を使用してください.未確認アカウントにファイルを送信しないでください.
