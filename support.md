# Support

Start with [troubleshooting](mrk-doctor/support/troubleshooting.md). If you need help, prepare:

- Minecraft/server software version and Java version.
- MRK Doctor version and edition.
- What happened, when it happened, and how to reproduce it.
- Relevant console errors and a reviewed diagnostic report.

Do not send dashboard tokens, passwords, full private configuration files, or unrelated player information.

The official support links have not yet been supplied. Use the verified support destination associated with your purchase; do not send files to unverified accounts.
