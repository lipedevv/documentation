# Länkarbord

I instrumentpanelen kan du granska servrarnas hälsa, incidenter, förändringar och annan diagnostisk information som finns i din utgåva.

Det kompletta instrumentpanelen är inbäddad i plugin JAR och serveras från den konfigurerade instrumentpanelen. Ingen separat Node.js eller Next.js -hosting krävs. Välj en tillgänglig allokering i din hostingpanel och följ [första inställningen](initial-setup.md).

Håll åtkomst begränsad till betrodda administratörer.

Om sidan öppnas men inte ansluter, följ [-problemlösning](../support/troubleshooting.md#dashboard-will-not-connect).
