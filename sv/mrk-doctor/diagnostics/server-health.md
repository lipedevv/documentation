# Kontrollera servers hälsa

Kör `/doctor status` eller öppna instrumentpanelen.

En lägre poäng innebär att servern behöver uppmärksamhet; den identifierar inte ett fel plugin på egen hand. Jämför läsningar över tid istället för att dra en slutsats från ett ögonblick.

Vissa mätningar är inte tillgängliga på äldre serverversioner. Kontrollera konsolen och använd servern stödda prestandaverktyg om mer detaljer behövs.

För ett aktivt problem, följ [undersöka en incident](incident-investigation.md).
