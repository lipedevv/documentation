# Snabb start

1. Kör `/doctor status` för att kontrollera aktuell server hälsa.
2. I spelet kör du `/doctor` för att öppna översikten.
3. Kör `/doctor incidents` för att se öppna problem.
4. Kör `/doctor changes` för att granska de senaste förändringarna.
5. Använd `/doctor report` när du behöver en rapport för stöd.

De första läsningarna kan ta lite tid efter start.

För webbåtkomst, följ [instrumentpanel konfiguration](../dashboard/initial-setup.md). För ett problem som redan påverkar spelare, öppna [felsökning](../support/troubleshooting.md).
