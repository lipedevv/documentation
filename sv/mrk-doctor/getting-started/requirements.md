# Föreskrifter

Den universella utgåvan riktar sig till Bukkit-kompatibla servrar från Minecraft **1.8.9 till 26.2**. Använd den version Java som krävs av din serverprogramvara. Håll din server och Java -installation stödd av sina respektive leverantörer.

Den optimerade Paper -utgåvan är en separat build för **Paper 1.21.x med Java 21**. Det är inte build för legacy servrar eller Paper 26.2.

{% hint style="warning" %}
Installa en MRK Doctor JAR endast. Installa aldrig de universella och optimerade Paper -utgåvorna tillsammans eller både skyddade och oskyddade kopior.
{% endhint %}

Det är inte nödvändigt att lägga till några ytterligare plugin. Lämna tillräckligt med utrymme på en disk för diagnoshistoria och exporterade rapporter.

En icke tillgänglig mätning betyder inte att din server är frisk eller fel.

Webb-dashboard är inbäddat i plugin JAR. Avståndsrörelse kräver en lämplig värdtilldelning och en säker webbadress eller omvänd proxy. Se [-dashboardinställning](../dashboard/initial-setup.md).
