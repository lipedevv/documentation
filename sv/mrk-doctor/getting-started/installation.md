# Installation

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Välj din fil
Använd Universal JAR om du inte specifikt behöver den optimerade Paper -utgåvan.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Stanna och bakåt.
Stäng Minecraft -servern normalt och gör en säkerhetskopiering innan du lägger till plugin.
{% endstep %}
{% step %}
<a id="install"></a>
#### Installation
Lägg ett MRK Doctor JAR i din servers mapp `plugins/` . Ta bort äldre kopior från den mappen.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Börja och kontrollera
Startar servern. Kontrollera att det inte finns några MRK Doctor startfel, och kör sedan `/doctor status` som operatör eller från konsolen. Ge tid för de första mätningarna.
{% endstep %}
{% endstepper %}

Fortsätt med [snabbstart](quick-start.md). Använd inte plugins-hot-loader för att installera eller byta ut MRK Doctor.
