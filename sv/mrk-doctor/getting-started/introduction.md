# Välkommen.

MRK Doctor hjälper serveradministratörer att undersöka lag, pluginfel och oväntade förändringar.

Du kan visa servers hälsa, kontrollera incidenter, granska senaste ändringar, kontrollera spelartillstånd och generera diagnostiska rapporter.

Börja med [installation](installation.md), följ sedan [snabbstart](quick-start.md).

{% hint style="info" %}
En misstänkt orsak är ett led till att undersöka, inte bevis på att ett plugin är fel. MRK Doctor reparerar inte automatiskt eller rullar tillbaka din server.
{% endhint %}
