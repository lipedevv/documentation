# Stöd

Börja med att felsöka [troubleshooting](mrk-doctor/support/troubleshooting.md). Om du behöver hjälp, förbereda:

- Minecraft/serverprogramvarur och Java -version.
- MRK Doctor -version och utgåva.
- Vad som hände, när det hände och hur man reproducerar det.
- Relevanta konsolfel och en reviderad diagnostisk rapport.

Skicka inte instrumentbransch tokens, lösenord, fullständiga privata konfigurationsfiler eller oberoende spelareinformation.

De officiella stödlänkarna har ännu inte tillhandahållits. Använd den verifierade stödresan som är kopplat till ditt köp; skicka inte filer till icke verifierade konton.
