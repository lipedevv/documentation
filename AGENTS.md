# MRK Doctor documentation instructions

- This is a single-product GitBook space, not Mintlify and not a multi-product portal.
- Read `SUMMARY.md` and `.gitbook.yaml` before restructuring content.
- Use Markdown, relative `.md` links, supported GitBook blocks, and Font Awesome page `icon` metadata.
- Preserve the original MRK logo and the purple/magenta identity described in `GITBOOK_SETUP.md`.
- Keep the Universal artifact as the main documented artifact. Label optimized Paper-only behavior explicitly.
- Verify technical claims against source code. Do not invent commands, integrations, support links, or legal policies.
- Write active, concise English in public pages; use sentence case for new headings.
- Public pages are for customers: installation, use, settings, permissions, support, and safety only.
- Never publish implementation architecture, algorithms, score formulas, database schemas, class/package names, developer APIs, or obfuscation details. Keep internal notes outside this repository.
- Preserve user-facing limitations and security notices without explaining implementation mechanisms.
- Run `npm run validate`; inspect the actual GitBook preview before claiming a visual review.
- Do not claim the site is published just because GitHub received a commit.
