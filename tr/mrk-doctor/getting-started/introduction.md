# Hoş geldiniz.

MRK Doktor, sunucu yöneticilerinin gecikme, eklenti hataları ve beklenmedik değişiklikleri araştırmasına yardımcı olur.

Sunucu sağlığını görüntüleyebilir, olayları kontrol edebilir, son değişiklikleri gözden geçirebilir, oyuncu izinlerini kontrol edebilir ve teşhis raporları oluşturabilirsiniz.

Start with [installation](installation.md), then follow the [quick start](quick-start.md).

{% hint style="info" %}
Bir şüpheli neden, bir eklentiin hatası olduğuna dair kanıt değil, araştırmak için bir ipucu. MRK Doktor otomatik olarak sunucunuzu onarmaz veya geri çevirmez.
{% endhint %}
