# Gereksinimler

Universal Edition, Minecraft **1.8.9 ile 26.2**arasındaki Bukkit uyumlu sunucuları hedeflemektedir. Server yazılımınız tarafından gerekli olan Java sürümünü kullanın. Serverinizi ve Java yüklemenizi ilgili tedarikçiler tarafından desteklenir.

The optimized Paper edition is a separate build for **Paper 1.21.x with Java 21**. It is not the build for legacy servers or Paper 26.2.

{% hint style="warning" %}
Bir MRK Doktor JAR'ı kur. Hiç Universal ve Optimized Paper baskılarını bir arada veya hem korumalı hem de korumalı olmayan kopyaları kurmayın.
{% endhint %}

Ek ek ekleme zorunlu değildir. Diagnostik geçmiş ve ihraç edilen raporlar için yeterli boş disk alanı bırakın.

Bazı ölçümler her sunucu sürümünde kullanılamıyor olabilir. Kullanılamaz bir ölçüm sunucunuzun sağlıklı veya bozuk olduğu anlamına gelmez.

The web dashboard is embedded in the plugin JAR. Remote access requires one suitable hosting allocation and a secure web address or reverse proxy. See [dashboard setup](../dashboard/initial-setup.md).
