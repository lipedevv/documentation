# Enregistrez une photo de diagnostic

Exécutez `/doctor snapshot`. La commande indique le chemin du fichier généré dans `plugins/MRKDoctor/snapshots/`.

Gardez une capture instantanée lors de l'enquête sur un problème ou avant de modifier la configuration d'un plugin.

{% hint style="warning" %}
Un instantané est un enregistrement de diagnostic, pas une sauvegarde serveur. Il ne peut pas restaurer des mondes, des fichiers de plugins, la configuration ou le dossier de données complet MRK Doctor. Maintenir des sauvegardes séparées.
{% endhint %}
