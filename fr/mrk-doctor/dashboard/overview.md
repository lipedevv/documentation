# Tableau de bord

Le tableau de bord vous permet de consulter la santé du serveur, les incidents, les changements et d'autres informations de diagnostic disponibles dans votre édition.

The complete dashboard is embedded in the plugin JAR and served from the configured dashboard port. No separate Node.js or Next.js hosting is required. Select an available allocation in your hosting panel and follow the [initial setup](initial-setup.md).

Gardez l'accès restreint aux administrateurs de confiance. Ne mettez pas les informations d'identification du tableau de bord dans les captures d'écran ou les messages de soutien public.

Si la page s' ouvre mais ne se connecte pas, suivez [pour résoudre les problèmes](../support/troubleshooting.md#dashboard-will-not-connect).
