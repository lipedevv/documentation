# Créer et partager un rapport

Exécutez `/doctor report` en tant qu' opérateur ou membre du personnel avec `mrkdoctor.report`. Attendez le message d' achèvement et ouvrez le fichier rapporté à partir de `plugins/MRKDoctor/reports/`.

L'édition universelle produit un rapport HTML qui peut être ouvert dans un navigateur.

Avant de partager:

1. Lisez le rapport complet et supprimez les informations non liées.
2. Recherchez les identifiants, les adresses privées, les chemins de fichiers, les détails du joueur et les valeurs de configuration sensibles.
3. Partagez uniquement les informations nécessaires pour enquêter sur la question.
4. Utilisez une destination de support vérifiée.

{% hint style="danger" %}
Le masquage automatique ne garantit pas que le rapport ne contient pas de secrets.
{% endhint %}

Incluez votre version Minecraft, la version MRK Doctor, une brève description, les étapes de reproduction et le moment où le problème s'est produit. Voir [support](../../support.md).
