# Exigences

L'édition universelle cible les serveurs compatibles avec Bukkit de Minecraft **1.8.9 à 26.2**. Utilisez la version Java requise par votre logiciel serveur. Gardez votre serveur et l'installation Java pris en charge par leurs fournisseurs respectifs.

L' édition Paper optimisée est une construction séparée pour **Paper 1.21.x avec Java 21**. Ce n' est pas la construction pour les serveurs hérités ou Paper 26.2.

{% hint style="warning" %}
N'installez jamais les éditions papier universelle et optimisée ensemble, ou les copies protégées et non protégées.
{% endhint %}

Aucun plugin supplémentaire n'est obligatoire. Laissez suffisamment d'espace disque libre pour l'historique de diagnostic et les rapports exportés.

Certaines mesures peuvent ne pas être disponibles sur toutes les versions du serveur.

Le tableau de bord Web est intégré dans le plugin JAR. L'accès à distance nécessite une allocation d'hébergement appropriée et une adresse Web sécurisée ou un proxy inverse. Voir [configuration du tableau de bord](../dashboard/initial-setup.md).
