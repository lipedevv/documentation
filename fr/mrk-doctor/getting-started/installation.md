# Installation

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Choisissez votre dossier
Utilisez le JAR universel à moins d'avoir besoin spécifiquement de l'édition papier optimisée.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Arrêtez et reculons
Arrêtez le serveur Minecraft normalement et faites une sauvegarde avant d'ajouter le plugin.
{% endstep %}
{% step %}
<a id="install"></a>
#### Installation
Placez un MRK Doctor JAR dans le dossier `plugins/` de votre serveur.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Commencez et vérifiez
Démarrez le serveur. Confirmez qu'il n'y a pas d'erreurs de démarrage MRK Doctor, puis exécutez `/doctor status` en tant qu'opérateur ou à partir de la console.
{% endstep %}
{% endstepper %}

Continuez avec [démarrage rapide](quick-start.md). N'utilisez pas de plug-in chargés chauds pour installer ou remplacer MRK Doctor.
