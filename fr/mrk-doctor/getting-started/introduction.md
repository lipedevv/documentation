# Bienvenue à vous .

MRK Doctor aide les administrateurs de serveurs à enquêter sur le retard, les erreurs de plugins et les changements inattendus.

Vous pouvez consulter la santé du serveur, inspecter les incidents, examiner les changements récents, vérifier les autorisations des joueurs et générer des rapports de diagnostic.

Commencez par l' installation de [installation](installation.md), puis suivez le démarrage rapide de [quick start](quick-start.md).

{% hint style="info" %}
Une cause suspectée est une piste à enquêter, pas une preuve qu'un plugin est en faute. MRK Doctor ne répare pas automatiquement ou ne rétablit pas votre serveur.
{% endhint %}
