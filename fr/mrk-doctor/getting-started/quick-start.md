# Début rapide

1. Exécutez `/doctor status` pour vérifier la santé actuelle du serveur.
2. Dans le jeu, exécutez `/doctor` pour ouvrir la vue d'ensemble.
3. Exécutez `/doctor incidents` pour voir les problèmes ouverts.
4. Exécutez `/doctor changes` pour examiner les modifications récentes.
5. Utilisez `/doctor report` lorsque vous avez besoin d'un rapport de soutien.

Les premières lectures peuvent prendre un peu de temps après le démarrage.

Pour accéder au web, suivez la configuration du tableau de bord [dashboard setup](../dashboard/initial-setup.md). Pour un problème qui affecte déjà les joueurs, ouvrez [troubleshooting](../support/troubleshooting.md).
