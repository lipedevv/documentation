# Mise à jour

1. Faites une sauvegarde du serveur et du dossier `plugins/MRKDoctor/` complet.
2. Arrêtez le serveur normalement.
3. Remplacez l'ancien JAR par le nouveau numéro de la même édition.
4. Revoir les notes de sortie et comparer la configuration fournie avec les paramètres existants.
5. Démarrez le serveur et vérifiez `/doctor status`, le tableau de bord et la console.

{% hint style="warning" %}
Une prise de vue diagnostique n'est pas une sauvegarde. Ne supposez pas que les options de configuration manquantes seront automatiquement ajoutées à un fichier existant.
{% endhint %}
