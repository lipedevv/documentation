# Investigate a problem

1. Confirm what players are experiencing and note when it started.
2. Run `/doctor status` and `/doctor incidents`.
3. Open the incident in the dashboard and read its available details and suggested checks.
4. Compare the timing with [recent changes](../changes/change-tracker.md).
5. Read relevant console errors and check the affected plugin's own documentation.
6. Save a [report](../reports/creating-reports.md) before changing the server.
7. Back up, make one reversible change, and observe the result.

{% hint style="warning" %}
Treat a suspected plugin and any confidence indication as investigation guidance, not a guarantee. MRK Doctor does not perform repairs, plugin updates, or rollback for you.
{% endhint %}
