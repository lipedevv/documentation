# Check server health

Run `/doctor status` or open the dashboard. Review the displayed health status together with player reports, current performance, memory use, and open incidents.

A lower score means the server needs attention; it does not identify a guilty plugin on its own. Compare readings over time instead of drawing a conclusion from one moment.

Some measurements are unavailable on older server versions. Check the console and use your server's supported performance tools if more detail is needed.

For an active problem, follow [investigate an incident](incident-investigation.md).
