# Uninstalling

Stop the server, then remove the MRK Doctor JAR from `plugins/`.

Keep `plugins/MRKDoctor/` if you may reinstall or need your existing history and reports. To remove that data too, archive the folder first and delete it only after verifying the backup.

Stop any separately hosted MRK Doctor dashboard application and remove its public route if you no longer use it.
