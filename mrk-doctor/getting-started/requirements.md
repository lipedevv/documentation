# Requirements

The Universal edition targets Bukkit-compatible servers from Minecraft **1.8.9 through 26.2**. Use the Java version required by your server software. Keep your server and Java installation supported by their respective vendors.

The optimized Paper edition is a separate build for **Paper 1.21.x with Java 21**. It is not the build for legacy servers or Paper 26.2.

{% hint style="warning" %}
Install one MRK Doctor JAR only. Never install the Universal and optimized Paper editions together, or both protected and unprotected copies.
{% endhint %}

No additional plugin is mandatory. Leave sufficient free disk space for diagnostic history and exported reports.

Some measurements may not be available on every server version. An unavailable measurement does not mean your server is healthy or broken.

The web dashboard is embedded in the plugin JAR. Remote access requires one suitable hosting allocation and a secure web address or reverse proxy. See [dashboard setup](../dashboard/initial-setup.md).
