# Welcome

MRK Doctor helps server administrators investigate lag, plugin errors, and unexpected changes.

You can view server health, inspect incidents, review recent changes, check player permissions, and generate diagnostic reports. The dashboard provides a web interface for reviewing the information available in your edition.

Start with [installation](installation.md), then follow the [quick start](quick-start.md).

{% hint style="info" %}
A suspected cause is a lead to investigate, not proof that a plugin is at fault. MRK Doctor does not automatically repair or roll back your server.
{% endhint %}
