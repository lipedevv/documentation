# Installation

{% stepper %}
{% step %}
#### Choose your file
Use the Universal JAR unless you specifically need the optimized Paper edition. The protected and unprotected JARs are alternative builds of the same edition.
{% endstep %}
{% step %}
#### Stop and back up
Stop the Minecraft server normally and make a backup before adding the plugin.
{% endstep %}
{% step %}
#### Install
Place one MRK Doctor JAR in your server's `plugins/` folder. Remove older copies from that folder.
{% endstep %}
{% step %}
#### Start and check
Start the server. Confirm there are no MRK Doctor startup errors, then run `/doctor status` as an operator or from the console. Allow time for the initial measurements.
{% endstep %}
{% endstepper %}

Continue with [quick start](quick-start.md). Do not use plugin hot-loaders to install or replace MRK Doctor.
