# Quick start

1. Run `/doctor status` to check current server health.
2. In game, run `/doctor` to open the overview.
3. Run `/doctor incidents` to see open problems.
4. Run `/doctor changes` to review recent tracked changes.
5. Use `/doctor report` when you need a report for support.

The first readings may take a little time after startup. Keep the server running before judging a new installation.

For web access, follow [dashboard setup](../dashboard/initial-setup.md). For a problem already affecting players, open [troubleshooting](../support/troubleshooting.md).
