# Dashboard

The dashboard lets you review server health, incidents, changes, and other diagnostic information available in your edition.

The plugin JAR does not serve the complete web application by itself. The dashboard application must be hosted separately and connected to your server. Use [initial setup](initial-setup.md) or ask your hosting administrator to help.

Keep access restricted to trusted administrators. Do not put dashboard credentials in screenshots or public support messages.

If the page opens but does not connect, follow [troubleshooting](../support/troubleshooting.md#dashboard-will-not-connect).
