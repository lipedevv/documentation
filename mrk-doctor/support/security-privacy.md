# Data and privacy

MRK Doctor collects diagnostic information about your server, its performance, errors, and tracked changes. Its standard operation stores diagnostic history locally and does not require an external analysis service.

Diagnostic files and dashboard access can reveal server details, paths, plugin configuration, or player-related information. Restrict access to trusted administrators, review exports before sharing, and retain only what you need.

Back up the full data folder before maintenance. If a credential is exposed, rotate it promptly.

For website legal-policy availability, see [privacy](../../privacy.md). Follow [dashboard security](../dashboard/security.md) for remote access.
