# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## O MRK Doctor corrige os problemas automaticamente?

Não, fornece diagnósticos para ajudá-lo a escolher um próximo passo seguro.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## Um plugin suspeito é definitivamente responsável?

Verifique o problema antes de culpar, remover ou substituir um plugin.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## Posso usar o painel de controlo logo após copiar o JAR?

Sim. O aplicativo do painel de instrumentos está incorporado no plugin JAR. Gerencie um token, configure uma porta acessível e siga a configuração de conexão [connection setup](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## Uma imagem de diagnóstico é um backup?

Mantenha backup separado de mundos, ficheiros de plugins, configuração e dados.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## Devo instalar ambas as edições ou ambas as variantes de proteção?

Não, instale apenas um JAR compatível.

<a id="can-i-share-reports-without-reviewing-them"></a>
## Posso compartilhar relatórios sem revisá-los?

Verifique sempre se há informações confidenciais, mesmo quando se tenha aplicado uma mascarada automática.
