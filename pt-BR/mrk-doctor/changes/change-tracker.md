# Revisão das mudanças recentes

Run `/doctor changes` or use the dashboard to review available plugin and configuration changes. `/doctor timeline` currently shows the same recent-change list in the Universal edition.

Comparar as timestamps com o problema relatado.Uma alteração que ocorre perto de um incidente é um contexto útil, mas não prova que causou o problema.

MRK Doctor não vê todos os arquivos ou substitui um sistema de backup externo. Para desativar uma mudança, pare o servidor e siga o procedimento de recuperação suportado pelo fornecedor de plugins afetados usando o seu próprio backup.

O rastreamento de mudanças pode ser habilitado ou desativado na configuração [configuration](../configuration/overview.md).
