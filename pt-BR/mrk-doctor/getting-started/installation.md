<a id="installation"></a>
# Instalação

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Escolha o seu ficheiro
Use o Universal JAR a menos que você precise especificamente da edição Paper otimizada.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Pára e recue .
Pare o servidor Minecraft normalmente e faça um backup antes de adicionar o plugin.
{% endstep %}
{% step %}
<a id="install"></a>
#### Instalação
Coloque um MRK Doctor JAR na pasta `plugins/` do seu servidor. Retire cópias antigas dessa pasta.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Comece e verifique
Inicie o servidor. Confirme que não há erros de inicialização do MRK Doctor , em seguida, execute o `/doctor status` como operador ou do console. Permita tempo para as medições iniciais.
{% endstep %}
{% endstepper %}

Continuar com [rápido início](quick-start.md). Não use plugins de carregamento de calor para instalar ou substituir MRK Doctor.
