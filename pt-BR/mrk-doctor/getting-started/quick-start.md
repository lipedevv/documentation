# Começo rápido

1. Execute `/doctor status` para verificar o estado atual do servidor.
2. No jogo, rodar `/doctor` para abrir a visão geral.
3. Exerce `/doctor incidents` para ver problemas abertos.
4. Execute `/doctor changes` para rever as alterações recentes rastreadas.
5. Use `/doctor report` quando precisar de um relatório de apoio.

As primeiras leituras podem demorar um pouco depois de iniciar. Mantém o servidor em funcionamento antes de julgar uma nova instalação.

Para acesso à web, siga a configuração do painel de controle [dashboard setup](../dashboard/initial-setup.md). Para um problema que já afeta os jogadores, abra [solução de problemas](../support/troubleshooting.md).
