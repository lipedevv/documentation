# Requisitos

A edição Universal visa servidores Bukkit-compatíveis a partir de Minecraft **1.8.9 até 26.2**. Use a versão Java exigida pelo seu software de servidor. Mantenha seu servidor e instalação Java suportados pelos respectivos fornecedores.

A edição Paper otimizada é uma construção separada para **Paper 1.21.x com Java 21**. Não é a construção para servidores legados ou Paper 26.2.

{% hint style="warning" %}
Instale apenas uma edição MRK Doctor JAR . Nunca instale as edições Universal e Otimizada Paper juntas, ou cópias protegidas e não protegidas.
{% endhint %}

Não é obrigatório nenhum plugin adicional. Deixe espaço livre suficiente no disco para histórico de diagnóstico e relatórios exportados.

Algumas medições podem não estar disponíveis em todas as versões do servidor.

O painel de controle da web está incorporado no plugin JAR. O acesso remoto requer uma alocação de hospedagem adequada e um endereço web seguro ou um proxy inverso . Consulte [configuração do painel de controle](../dashboard/initial-setup.md).
