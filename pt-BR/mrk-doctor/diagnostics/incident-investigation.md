# Investigar um problema

1. Confirme o que os jogadores estão a experimentar e note quando começou.
2. Execute `/doctor status` e `/doctor incidents`.
3. Abre o incidente no painel e leia os detalhes disponíveis e as propostas de verificação.
4. Compare o tempo com o [alterações recentes](../changes/change-tracker.md).
5. Leia os erros relevantes do console e verifique a própria documentação do plugin afetado.
6. Salvar um relatório [report](../reports/creating-reports.md) antes de mudar o servidor.
7. Retrocede, faça uma mudança reversível e observe o resultado.

{% hint style="warning" %}
Trate um plugin suspeito e qualquer indicação de confiança como uma orientação de investigação, não uma garantia. MRK Doctor não realiza reparos, atualizações de plugins ou rollback para você.
{% endhint %}
