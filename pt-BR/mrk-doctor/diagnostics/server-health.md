# Verifique o estado do servidor

Execute `/doctor status` ou abra o painel de controle. Revisar o estado de saúde exibido junto com relatórios de jogadores, desempenho atual, uso de memória e incidentes abertos.

Uma pontuação mais baixa significa que o servidor precisa de atenção; ele não identifica um plugin culpado por si mesmo.

Algumas medições não estão disponíveis em versões anteriores do servidor. Verifique o console e use as ferramentas de desempenho suportadas do servidor se for necessário mais detalhes.

Para um problema ativo, siga [investigar um incidente](incident-investigation.md).
