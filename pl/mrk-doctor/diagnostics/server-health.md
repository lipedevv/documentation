# Sprawdź stan serwera

Uruchomić `/doctor status` lub otworzyć deskę.

O niższym wyniku chodzi o to, że serwer potrzebuje uwagi, nie identyfikuje wtyczki winna samodzielnie.

Niektóre pomiary nie są dostępne na starszych wersjach serwera. Sprawdź konsolę i użyj obsługiwanych narzędzi wydajności serwera, jeśli potrzeba więcej szczegółów.

W przypadku aktywnego problemu, śledź [, zbadaj incydent](incident-investigation.md).
