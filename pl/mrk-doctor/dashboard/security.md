# Bezpieczeństwo deski kontrolnej

- Udzielić dostępu tylko zaufanym administratorom.
- Użyj HTTPS dla deski kontrolnej internetowej i zabezpieczaj połączenia z jej usługami.
- Zachowaj domyślne lokalne wiązanie, gdy usługi uruchamiają się na tym samym hostie.
- Ochrona hostowanych alokacji za pomocą zapory i reguł proxy.
- Zwróć token z `/doctor dashboard setup` , jeśli jest wystawiony.
- Przejrzyj raporty i zdjęcia ekranu, zanim je wysłasz komuś.

Nigdy nie wklej tokenu deski rozdzielczej do publicznego problemu, kanału Discord lub przykładu konfiguracji. Jeśli nie potrzebujesz dostępu do sieci, wyłącz `doctor.dashboard.enabled` i uruchomi ponownie.
