# Dane i prywatność

MRK Doctor zbiera informacje diagnostyczne o serwerze, jego wydajności, błędach i śledzeniach zmian.

Pliki diagnostyczne i dostęp do deski kontrolnej mogą ujawniać szczegóły serwera, ścieżki, konfigurację wtyczki lub informacje dotyczące gracza. Ogranicz dostęp do zaufanych administratorów, przeglądaj eksport przed udostępnieniem i zachowaj tylko to, czego potrzebujesz.

Jeśli zostanie ujawniona dokumentacja, natychmiast ją odwróć.

For website legal-policy availability, see [privacy](../../privacy.md). Follow [dashboard security](../dashboard/security.md) for remote access.
