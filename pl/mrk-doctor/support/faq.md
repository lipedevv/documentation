# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## Czy doktor MRK automatycznie rozwiązuje problemy?

Nie, dostarcza diagnostykę, która pomoże ci wybrać bezpieczny następny krok.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## Czy podejrzany wtyczka jest zdecydowanie odpowiedzialny?

Nie, sprawdź problem, zanim obwinisz, usunie lub zastąpisz wtyczkę.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## Czy mogę skorzystać z deski zarządczej natychmiast po kopiowaniu JAR?

Tak. Aplikacja panela jest wbudowana w wtyczkę JAR. Zgeneruj token, skonfiguruj jeden dostępny port i wykonaj ustawienie połączenia [connection setup](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## Czy zdjęcie diagnostyczne jest rezerwą?

Nie, zachowuj oddzielne kopie zapasowe światów, plików wtyczki, konfiguracji i danych.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## Mam zainstalować oba wydania czy obie warianty ochrony?

Nie, instaluj tylko jeden kompatybilny JAR.

<a id="can-i-share-reports-without-reviewing-them"></a>
## Czy mogę podzielić się raportami bez ich przeglądu?

Zawsze sprawdzaj, czy nie ma informacji wrażliwych, nawet jeśli zastosowano maskowanie automatyczne.
