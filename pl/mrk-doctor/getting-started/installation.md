<a id="installation"></a>
# Instalacja

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Wybierz swój plik
Użyj Uniwersalnego JAR, chyba że potrzebujesz optymalizowanej edycji papierowej.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Zatrzymaj się i odwróć się .
Zatrzymaj normalny serwer Minecraft i wykonaj kopie zapasowe przed dodaniem wtyczki.
{% endstep %}
{% step %}
<a id="install"></a>
#### Instalowanie
Wstaw jedną MRK Doctor JAR w folderze `plugins/` serwera.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Zacznij i sprawdź
Uruchomić serwer. Potwierdź, że nie ma błędów w uruchomieniu MRK Doctor, a następnie uruchomić `/doctor status` jako operator lub z konsoli.
{% endstep %}
{% endstepper %}

Kontynuuj z [szybki start](quick-start.md). Nie używaj wtyczek do instalacji lub wymiany MRK Doctor.
