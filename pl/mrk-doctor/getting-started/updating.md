# Aktualne

1. Zapewnienie serwera i pełnego folderu `plugins/MRKDoctor/` .
2. Zatrzymaj serwer normalnie.
3. Zastąpić stare JAR nową wersją tego samego wydania.
4. Przejrzyj notatki o wypuszczeniu i porównaj dostarczoną konfigurację z istniejącymi ustawieniami.
5. Uruchom serwer i sprawdź `/doctor status`, deskę i konsołę.

{% hint style="warning" %}
Zdjęcie diagnostyczne nie jest kopiowaniem. Nie zakładaj, że brakujące opcje konfiguracji zostaną automatycznie dodane do istniejącego pliku.
{% endhint %}
