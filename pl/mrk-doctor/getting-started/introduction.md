# Witamy .

MRK Doctor pomaga administratorom serwera badać opóźnienia, błędy w wtyczki i nieoczekiwane zmiany.

Możesz przeglądać stan serwera, sprawdzić incydenty, przeglądać ostatnie zmiany, sprawdzić uprawnienia gracza i generować raporty diagnostyczne.

Zacznij od instalacji [installation](installation.md), a następnie idź po [szybki start](quick-start.md).

{% hint style="info" %}
Podejrzewana przyczyna jest wskazówką do zbadania, a nie dowodem na to, że wtyczka jest winna.
{% endhint %}
