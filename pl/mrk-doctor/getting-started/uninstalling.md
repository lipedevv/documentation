# Uninstalling

Zatrzymaj serwer, a potem usuwaj MRK Doctor JAR z `plugins/`.

Zachowaj `plugins/MRKDoctor/` , jeśli możesz zainstalować lub potrzebować istniejącej historii i raportów. Aby usunąć te dane, najpierw archiwuj folder i usunąć go dopiero po weryfikacji kopii zapasowej.

Usunąć wszelkie trasy odwrotnej proxy lub przydział hostingu, który wystawił wbudowany panel kontrolny MRK Doctor.
