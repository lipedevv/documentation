# Wymogi

Universal edition dotyczy serwerów zgodnych z bukkitami od Minecraft **1.8.9 do 26.2**. Użyj wersji Java wymaganej przez oprogramowanie serwera. Utrzymaj serwer i instalację Java obsługiwane przez ich odpowiednich dostawców.

Optymalizowana edycja Paper jest oddzielną wersją **Paper 1.21.x z Java 21**. Nie jest ona wersją dla serwerów dziedzicznych ani Papieru 26.2.

{% hint style="warning" %}
Nigdy nie instaluj uniwersalnych i zoptymalizowanych edycji papierowych razem, ani chronionych i niezabezpieczonych kopii.
{% endhint %}

Nie ma dodatkowego wtyczki. Zostaw wystarczająco wolnego miejsca na dysku dla historii diagnostyki i raportów eksportowanych.

Niektóre pomiary mogą nie być dostępne na każdej wersji serwera.

Wbudowany w wbudowaną wbudowę JAR. Dostęp zdalny wymaga odpowiedniego alokacji hostingu i bezpiecznego adresu internetowego lub odwrotnego proxy. Zobacz konfigurację wbudowy [dashboard setup](../dashboard/initial-setup.md).
