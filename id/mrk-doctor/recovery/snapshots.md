# Simpan snapshot diagnostik

Jalankan `/doctor snapshot`. Komando melaporkan jalur file yang dihasilkan di `plugins/MRKDoctor/snapshots/`.

Simpan gambar saat menyelidiki masalah atau sebelum mengubah konfigurasi plugin. Periksa untuk informasi sensitif sebelum membagikannya.

{% hint style="warning" %}
Snapshot adalah catatan diagnostik, bukan cadangan server. Tidak dapat mengembalikan dunia, file plugin, konfigurasi, atau folder data MRK Doctor lengkap. Pertahankan cadangan terpisah.
{% endhint %}
