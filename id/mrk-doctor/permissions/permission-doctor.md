# Periksa izin dan perintah

Pemain target harus online.

```text
/doctor permission Steve essentials.warp
/doctor command Steve warp
```

Komando pertama memeriksa izin yang ditentukan. Komando kedua membantu mengidentifikasi plugin perintah dan memeriksa akses.

Jika akses masih gagal, periksa sintaksis perintah, konfigurasi kelompok izin, pembatasan dunia, dan cooldown. MRK Doctor tidak mengubah izin pemain atau menggantikan manajer izin Anda.

Pemeriksaan ini tersedia untuk pengguna dengan `mrkdoctor.view`, jadi berikan node itu hanya kepada staf yang dapat diandalkan.
