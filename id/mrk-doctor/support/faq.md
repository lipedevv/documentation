# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## Apakah MRK Doctor memperbaiki masalah secara otomatis?

Tidak, ini menyediakan diagnostik untuk membantu Anda memilih langkah selanjutnya yang aman.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## Apakah plugin yang diduga pasti bertanggung jawab?

Tidak, periksa masalah sebelum menyalahkan, menghapus, atau mengganti plugin.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## Bisakah aku menggunakan dashboard segera setelah menyalin JAR?

Ya. Aplikasi dashboard tertanam dalam plugin JAR. Menghasilkan token, mengkonfigurasi satu port yang dapat diakses, dan mengikuti pengaturan koneksi [connection setup](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## Apakah foto diagnostik adalah cadangan?

Tidak, menyimpan cadangan terpisah dari dunia, file plugin, konfigurasi, dan data.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## Haruskah saya memasang kedua edisi atau kedua varian perlindungan?

Tidak, hanya memasang satu JAR yang kompatibel.

<a id="can-i-share-reports-without-reviewing-them"></a>
## Bisakah aku berbagi laporan tanpa meninjau mereka?

Selalu periksa informasi sensitif, bahkan ketika masker otomatis telah diterapkan.
