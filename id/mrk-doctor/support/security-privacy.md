# Data dan privasi

MRK Doctor mengumpulkan informasi diagnostik tentang server Anda, kinerja, kesalahan, dan perubahan pelacakan. Operasi standarnya menyimpan sejarah diagnostik secara lokal dan tidak memerlukan layanan analisis eksternal.

File diagnostik dan akses ke dashboard dapat mengungkapkan rincian server, jalur, konfigurasi plugin, atau informasi terkait pemain. Batasi akses ke administrator yang dapat diandalkan, meninjau ekspor sebelum berbagi, dan simpan hanya apa yang Anda butuhkan.

Membuat cadangan folder data lengkap sebelum pemeliharaan. Jika kredensial terpapar, putarkannya segera.

Untuk ketersediaan kebijakan hukum situs web, lihat [privasi](../../privacy.md). Ikuti [keamanan dasbor](../dashboard/security.md) untuk akses jarak jauh.
