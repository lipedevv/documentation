# Ketersediaan dan keterbatasan

- Dokter MRK memberikan panduan diagnostik, tidak menjamin identifikasi penyebab akar.
- Ini tidak secara otomatis memperbarui plugin, memperbaiki file, mengembalikan cadangan, atau memutar kembali perubahan.
- Snapshot adalah catatan diagnostik, bukan cadangan server yang dapat dipulihkan.
- Pelacakan penutur yang terperinci dan pelacakan lambat tidak tersedia dalam rilis ini.
- Beberapa ukuran dan fitur bervariasi berdasarkan versi dan edisi server.
- Pemantauan perubahan baru-baru ini tidak mencakup setiap file server.
- Akses dari remote dashboard masih tergantung pada port yang dapat dicapai atau proxy terbalik yang disediakan oleh host server.
- Masking otomatis tidak dapat menjamin bahwa laporan tidak mengandung informasi sensitif.

Untuk masalah yang belum teratasi, [dukungan kontak](../../support.md) dengan laporan yang ditinjau dan deskripsi yang jelas.
