# Periksa kesehatan server

Jalankan `/doctor status` atau buka dashboard. Periksa status kesehatan yang ditampilkan bersama dengan laporan pemain, kinerja saat ini, penggunaan memori, dan insiden terbuka.

Skor yang lebih rendah berarti server membutuhkan perhatian; tidak mengidentifikasi plugin yang bersalah sendiri. Bandingkan pembacaan dari waktu ke waktu daripada menarik kesimpulan dari satu saat.

Beberapa pengukuran tidak tersedia pada versi server yang lebih lama. Periksa konsol dan gunakan alat kinerja server yang didukung jika perlu lebih detail.

Untuk masalah aktif, ikuti [menyelidiki insiden](incident-investigation.md).
