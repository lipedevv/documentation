# Dashboard

Dashboard memungkinkan Anda meninjau kesehatan server, insiden, perubahan, dan informasi diagnostik lainnya yang tersedia dalam edisi Anda.

The complete dashboard is embedded in the plugin JAR and served from the configured dashboard port. No separate Node.js or Next.js hosting is required. Select an available allocation in your hosting panel and follow the [initial setup](initial-setup.md).

Jaga akses terbatas kepada administrator yang dapat diandalkan. Jangan memasukkan kredensial dashboard ke dalam gambar layar atau pesan dukungan publik.

Jika halaman dibuka tetapi tidak terhubung, ikuti [untuk memecahkan masalah](../support/troubleshooting.md#dashboard-will-not-connect).
