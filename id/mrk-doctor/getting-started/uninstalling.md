# Menghapus

Hentikan server, lalu hapus MRK Doctor JAR dari `plugins/`.

Simpan `plugins/MRKDoctor/` jika Anda mungkin menginstal ulang atau membutuhkan riwayat dan laporan yang ada. Untuk menghapus data itu juga, arsipkan folder terlebih dahulu dan hapus saja setelah memverifikasi cadangan.

Hapus rute reverse proxy atau alokasi hosting yang mengekspos dashboard MRK Doctor tertanam.
