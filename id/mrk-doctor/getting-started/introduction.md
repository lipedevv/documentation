# Selamat datang.

MRK Doctor membantu administrator server menyelidiki keterlambatan, kesalahan plugin, dan perubahan yang tidak terduga.

Anda dapat melihat kesehatan server, memeriksa insiden, meninjau perubahan baru-baru ini, memeriksa izin pemain, dan menghasilkan laporan diagnostik. Dashboard menyediakan antarmuka web untuk meninjau informasi yang tersedia dalam edisi Anda.

Mulailah dengan instalasi [installation](installation.md), lalu ikuti [cepat start](quick-start.md).

{% hint style="info" %}
Penyebab tersangka adalah petunjuk untuk menyelidiki, bukan bukti bahwa plugin salah. MRK Doctor tidak secara otomatis memperbaiki atau membalikkan server Anda.
{% endhint %}
