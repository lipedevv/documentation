# Pembaruan

1. Membuat cadangan server dan folder lengkap `plugins/MRKDoctor/` .
2. Hentikan server normal.
3. Tukarkan JAR lama dengan versi baru dari edisi yang sama.
4. Periksa catatan rilis dan bandingkan konfigurasi yang disediakan dengan pengaturan yang ada.
5. Mulai server dan periksa `/doctor status`, dashboard, dan konsol.

{% hint style="warning" %}
Sebuah snapshot diagnostik bukan cadangan. Jangan berasumsi bahwa opsi konfigurasi yang hilang akan ditambahkan ke file yang ada secara otomatis.
{% endhint %}
