# Mulai cepat

1. Jalankan `/doctor status` untuk memeriksa status server saat ini.
2. Dalam permainan, jalankan `/doctor` untuk membuka gambaran umum.
3. Putar `/doctor incidents` untuk melihat masalah terbuka.
4. Jalankan `/doctor changes` untuk meninjau perubahan yang baru-baru ini dilacak.
5. Gunakan `/doctor report` jika Anda membutuhkan laporan dukungan.

Pembacaan pertama mungkin membutuhkan waktu beberapa saat setelah startup.

Untuk akses web, ikuti pengaturan dashboard [dashboard setup](../dashboard/initial-setup.md). Untuk masalah yang sudah mempengaruhi pemain, buka [pemecahan masalah](../support/troubleshooting.md).
