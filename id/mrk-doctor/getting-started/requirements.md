# Persyaratan

Edisi Universal menargetkan server Bukkit-kompatibel dari Minecraft **1.8.9 sampai 26.2**. Gunakan versi Java yang dibutuhkan oleh perangkat lunak server Anda. Jaga server dan instalasi Java Anda didukung oleh vendor masing-masing.

Edisi Paper yang dioptimalkan adalah build terpisah untuk **Paper 1.21.x dengan Java 21**. Ini bukan build untuk server legacy atau Paper 26.2.

{% hint style="warning" %}
Jangan pernah memasang Universal dan Optimized Paper editions bersama, atau kedua salinan yang dilindungi dan tidak dilindungi.
{% endhint %}

Tidak ada plugin tambahan yang wajib. Tinggalkan ruang disk yang cukup untuk sejarah diagnostik dan laporan ekspor.

Beberapa pengukuran mungkin tidak tersedia pada setiap versi server. Pengukuran tidak tersedia tidak berarti server Anda sehat atau rusak.

Dashboard web tertanam dalam plugin JAR. Akses jarak jauh membutuhkan alokasi hosting yang tepat dan alamat web yang aman atau proxy terbalik. Lihat pengaturan dashboard [dashboard setup](../dashboard/initial-setup.md).
