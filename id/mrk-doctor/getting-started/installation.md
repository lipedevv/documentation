<a id="installation"></a>
# Instalasi

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Pilih file Anda
Gunakan JAR Universal kecuali jika Anda secara khusus membutuhkan edisi Paper yang dioptimalkan. JAR yang dilindungi dan tidak dilindungi adalah versi alternatif dari edisi yang sama.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Berhenti dan mundur
Hentikan server Minecraft secara normal dan membuat cadangan sebelum menambahkan plugin.
{% endstep %}
{% step %}
<a id="install"></a>
#### Instal
Masukkan satu MRK Doctor JAR ke folder `plugins/` server Anda. Hapus salinan lama dari folder itu.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Mulai dan periksa
Mulai server. Konfirmasi tidak ada kesalahan startup MRK Doctor, lalu jalankan `/doctor status` sebagai operator atau dari konsol. Beri waktu untuk pengukuran awal.
{% endstep %}
{% endstepper %}

Lanjutkan dengan [start cepat](quick-start.md). Jangan menggunakan plugin hot-loader untuk menginstal atau mengganti MRK Doctor.
