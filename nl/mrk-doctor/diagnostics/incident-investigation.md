# Onderzoek een probleem

1. Confirmeer wat de spelers ervaren en merk op wanneer het begon.
2. Run `/doctor status` en `/doctor incidents`.
3. Open het incident in het dashboard en lees de beschikbare details en suggereerde controles.
4. Vergelijk de timing met [recente wijzigingen](../changes/change-tracker.md).
5. Lees relevante consolefouten en controleer de eigen documentatie van de betrokken plugin.
6. Bewaar een [-rapport](../reports/creating-reports.md) voordat u de server verandert.
7. Ga terug, maak één omkeerbare verandering en observeer het resultaat.

{% hint style="warning" %}
Behandelt een vermoedelijke plugin en alle vertrouwensindicatoren als onderzoeksrichtlijn, geen garantie. MRK Doctor doet geen reparaties, plug-in updates of rollback voor u.
{% endhint %}
