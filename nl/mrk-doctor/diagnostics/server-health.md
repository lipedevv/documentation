# Controleer de gezondheid van de server

Run `/doctor status` of open het dashboard. Bekijk de weergegeven gezondheidsstatus samen met spelerrapporten, actuele prestaties, geheugengebruik en open incidenten.

Een lagere score betekent dat de server aandacht nodig heeft; het identificeert geen schuldige plugin op zichzelf. Vergelijk de lezingen met de tijd in plaats van een conclusie te trekken uit één moment.

Sommige metingen zijn niet beschikbaar op oudere serverversie. Controleer de console en gebruik de ondersteunde prestatietools van uw server als meer details nodig zijn.

Voor een actief probleem, volg [een incident onderzoeken](incident-investigation.md).
