# Bewaar een diagnose snapshot

Run `/doctor snapshot`. Het commando meldt het pad van het gegenereerde bestand in `plugins/MRKDoctor/snapshots/`.

Bewaar een snapshot bij het onderzoeken van een probleem of voordat u een plugin configuratie wijzigt.

{% hint style="warning" %}
Een snapshot is een diagnostisch record, geen server back-up. Het kan werelden, plug-in bestanden, configuratie of de volledige MRK Doctor-data map niet herstellen.
{% endhint %}
