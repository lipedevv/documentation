# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## Herstelt MRK-arts problemen automatisch?

Nee, het biedt diagnose om je te helpen een veilige volgende stap te kiezen.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## Is een verdachte plugin zeker verantwoordelijk?

Controleer het probleem voordat je een plugin verwijdert of vervangt.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## Kan ik het dashboard direct gebruiken nadat ik de JAR heb gekopieerd?

Ja. De dashboard-applicatie is ingebed in de plugin JAR. Genereren van een token, configureer een bereikbare poort, en volg de [verbinding opstelling](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## Is een diagnose snapshot een back-up?

Nee, hou afzonderlijke back-ups van werelden, plug-in bestanden, configuratie en gegevens.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## Moet ik beide edities of beide beschermingsvarianten installeren?

Installeer maar één compatibel JAR.

<a id="can-i-share-reports-without-reviewing-them"></a>
## Kan ik rapporten delen zonder ze te beoordelen?

Nee, controleer altijd op gevoelige informatie, zelfs wanneer automatische maskering is toegepast.
