<a id="installation"></a>
# Installatie

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Kies uw dossier
Gebruik de Universal JAR tenzij u specifiek de geoptimaliseerde papier-uitgave nodig heeft.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Stop en terug.
Stop de Minecraft-server normaal en maak een back-up voordat je de plugin toevoegt.
{% endstep %}
{% step %}
<a id="install"></a>
#### Installatie
Plaats een MRK Doctor JAR in de `plugins/` map van je server.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Begin en controleer
Start de server. Bevestig dat er geen MRK Doctor-startfouten zijn, voer `/doctor status` dan uit als operator of vanaf de console. Geef tijd voor de eerste metingen.
{% endstep %}
{% endstepper %}

Ga door met [snelstart](quick-start.md). Gebruik geen plug-in-hot-loaders om MRK Doctor te installeren of te vervangen.
