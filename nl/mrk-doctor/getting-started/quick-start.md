# Snel starten

1. Run `/doctor status` om de huidige gezondheid van de server te controleren.
2. In het spel, run `/doctor` om het overzicht te openen.
3. Run `/doctor incidents` om open problemen te zien.
4. Run `/doctor changes` om recente veranderingen te bekijken.
5. Gebruik `/doctor report` wanneer u een rapport voor ondersteuning nodig hebt.

De eerste aflezen kunnen een tijdje duren na het starten.

Voor webtoegang volg [dashboard setup](../dashboard/initial-setup.md). Voor een probleem dat spelers al treft, open [troubleshooting](../support/troubleshooting.md).
