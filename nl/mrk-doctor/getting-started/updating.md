# Bijgewerkte

1. Bewaar de server en de volledige `plugins/MRKDoctor/` map.
2. Stop de server normaal.
3. Vervang de oude JAR met de nieuwe versie van dezelfde uitgave.
4. Bekijk de release- notities en vergelijk de geleverde configuratie met uw bestaande instellingen.
5. Start de server en check `/doctor status`, het dashboard en de console.

{% hint style="warning" %}
Een diagnostische snapshot is geen back-up.
{% endhint %}
