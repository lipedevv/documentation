# Welkom .

MRK Doctor helpt serveradministratoren om lag, pluginfouten en onverwachte veranderingen te onderzoeken.

U kunt de gezondheid van de server bekijken, incidenten controleren, recente wijzigingen bekijken, de spelersbevoegdheden controleren en diagnostische rapporten genereren.

Begin met [installatie](installation.md), volg dan de [snelstart](quick-start.md).

{% hint style="info" %}
Een vermoedelijke oorzaak is een aanwijzing om te onderzoeken, niet het bewijs dat een plugin fout heeft. MRK Doctor herstelt of rollt uw server niet automatisch terug.
{% endhint %}
