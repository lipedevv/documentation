# Verplichtingen

De Universal editie is gericht op Bukkit-compatibele servers van Minecraft **1.8.9 tot 26.2**. Gebruik de Java-versie die vereist is voor uw serversoftware. Hou uw server en Java-installatie ondersteund door hun respectieve leveranciers.

De geoptimaliseerde Paper edition is een aparte build voor **Paper 1.21.x met Java 21**. Het is niet de build voor legacy servers of Paper 26.2.

{% hint style="warning" %}
Installeer alleen één MRK Doctor JAR. Installeer nooit de Universal en geoptimaliseerde Paper edities samen, of zowel beschermde als onbeschermde kopieën.
{% endhint %}

Er is geen extra plugin verplicht. Laat voldoende vrije schijfruimte achter voor diagnostische geschiedenis en uitgevoerde rapporten.

Sommige metingen zijn mogelijk niet beschikbaar op alle serverversie.

Het web dashboard is ingebed in de plugin JAR. Remote toegang vereist een geschikte hosting toewijzing en een beveiligd webadres of een omgekeerd proxy. Zie [dashboard opstelling](../dashboard/initial-setup.md).
