# مرحباً بك

يُساعد MRK Doctor مدراء الخادم على التحقيق في التأخيرات، أخطاء المكونات التضمينية، والتغييرات غير المتوقعة.

يمكنك عرض حالة الخادم، ومراجعة الحوادث، ومراجعة التغييرات الأخيرة، ومراجعة الإذنات اللاعب، وإنشاء تقارير تشخيصية. يقدم لوحة التحكم واجهة الويب لمراجعة المعلومات المتاحة في الطبعة الخاصة بك.

ابدأ بتثبيت [installation](installation.md)، ثم اتبع [بدء سريع](quick-start.md).

{% hint style="info" %}
السبب المشتبه به هو دليل للتحقيق، وليس دليل على أن المكونات المضافة هي الخطأ. لا يقوم الطبيب MRK بإصلاح أو إعادة تشغيل الخادم الخاص بك تلقائيا.
{% endhint %}
