<a id="installation"></a>
# التثبيت

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### اختر ملفك
استخدم JAR العالمي ما لم تكن بحاجة بشكل خاص إلى الطبعة الورقية المثلى. JAR المحمية وغير المحمية هي إصدارات بديلة من نفس الطبعة.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### توقفوا و تراجعوا
أوقف خادم Minecraft بشكل طبيعي و قم بتحميل النسخة الاحتياطية قبل إضافة المكونات التضافية.
{% endstep %}
{% step %}
<a id="install"></a>
#### إثباط
ضع جرة MRK Doctor JAR في المجلد `plugins/` على خادمك وإزالة النسخ القديمة من هذا المجلد
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### ابدأ وتحقق
تشغيل الخادم. تأكد من عدم وجود أخطاء بدء MRK Doctor ، ثم تشغيل `/doctor status` كعميل أو من جهاز الاشتراك. إسمح بوقت للقياسات الأولية.
{% endstep %}
{% endstepper %}

استمر في [بدء سريع](quick-start.md). لا تستخدم مشغليات التحميل الساخن لنشط MRK Doctor أو استبدالها.
