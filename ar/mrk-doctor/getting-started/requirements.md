# المتطلبات

الإصدار العالمي يستهدف الخوادم المتوافقة مع Bukkit من Minecraft **1.8.9 إلى 26.2**. استخدم إصدار Java المطلوب من برنامج الخادم الخاص بك. حافظ على خدمة Java وتثبيتها مدعومة من قبل مورديها.

إصدار ورق المحسن هو بناء منفصل ل **ورق 1.21.x مع جاوا 21**. انها ليست بناء للخدمات التراثية أو ورق 26.2.

{% hint style="warning" %}
لا تثبيت إصدارات ورقية عالمية ومحسنة معاً، أو كل من النسخ المحمية وغير المحمية.
{% endhint %}

لا توجد مكونات إضافية إلزامية. اترك مساحة قائمة كافية للتاريخ التشخيصي والتقارير المصدرة.

قد لا تكون بعض القياسات متاحة على كل نسخة من خادمات. لا يعني عدم توفر القياس أن خادمك صحي أو محطم.

يتم دمج لوحة التحكم على الويب في مكونات المكونات JAR. يتطلب الوصول عن بعد توزيعًا مناسبًا للمضيف والعنوان الويب الآمن أو الوكيل العكسي. انظر إعداد لوحة التحكم [dashboard setup](../dashboard/initial-setup.md).
