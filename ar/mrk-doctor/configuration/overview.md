# التشغيل

قم بتحرير `plugins/MRKDoctor/config.yml` مع محرر نصي يمل واعي. قم بنسخ احتياطي أولاً واحفظ بالدخل.

التكوين الافتراضي هو نقطة بداية جيدة. قم بتغيير الإعدادات التي تحتاجها فقط، مثل علامة الخادم، فترات المراقبة، وصول لوحة التحكم، أو حفظ التاريخ.

تصبح إثباتات لوحة التحكم التي تم إنشاؤها بواسطة `/doctor dashboard setup` نشطة على الفور. إعادة تشغيل بعد تغيير عناوين الالتزام أو الموانئ أو الحالة المكافحة أو إعدادات المراقبة. لا يمكن إعادة تشغيل `/doctor reload` بالكامل لتغييرات الاتصال وتغيرات دورة الحياة.

استخدم مرجع تشكيل [configuration reference](../reference/configuration.md) للطبعة العالمية. لا تنسخ الإعدادات الإضافية من الطبعة الأخرى وتفترض أنها ستؤدي إلى ميزات جديدة.
