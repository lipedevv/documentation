# الدعم

ابدأ بإصلاح المشاكل [troubleshooting](mrk-doctor/support/troubleshooting.md). إذا كنت بحاجة إلى مساعدة ، إعد:

- نسخة برنامج Minecraft/Server و نسخة Java
- نسخة وطبعة MRK Doctor.
- ما حدث، متى حدث، وكيفية إعادة إنتاجها
- أخطاء الموافقة ذات الصلة وتقرير تشخيص معالجة.

لا ترسل رموز لوحة التحكم أو كلمات مرور أو ملفات تشكيل خاصة كاملة أو معلومات لاعبي غير مرتبطة.

لا يتم توفير الروابط الرسمية للدعم بعد. استخدم وجهة الدعم المحققة المرتبطة بشراءك؛ لا ترسل الملفات إلى الحسابات غير المحققة.
