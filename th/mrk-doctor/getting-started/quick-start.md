# เริ่มเร็ว

1. วิ่ง `/doctor status` เพื่อตรวจสอบสถานการณ์ของเซอร์เวอร์ปัจจุบัน
2. ในเกม, วิ่ง `/doctor` เพื่อเปิดภาพรวม
3. วิ่ง `/doctor incidents` เพื่อดูปัญหาที่เปิด
4. วิ่ง `/doctor changes` เพื่อตรวจสอบการเปลี่ยนแปลงที่ติดตามล่าสุด
5. ใช้ `/doctor report` เมื่อต้องการรายงานสนับสนุน

การอ่านครั้งแรกอาจใช้เวลาเล็กน้อยหลังจากเริ่มต้น ให้เซอร์เวอร์ทํางานก่อนที่จะตัดสินการติดตั้งใหม่

สําหรับการเข้าถึงเว็บ, ติดตามการตั้งค่าดัชบอร์ด [dashboard setup](../dashboard/initial-setup.md). สําหรับปัญหาที่มีผลกระทบต่อผู้เล่น, เปิด [การแก้ไขปัญหา](../support/troubleshooting.md).
