<a id="installation"></a>
# การติดตั้ง

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### เลือกไฟล์ของคุณ
ใช้ JAR มหาลัย เว้นแต่คุณต้องการการพิมพ์กระดาษที่อุดมสมบูรณ์แบบ โดย JAR ที่คุ้มครองและไม่คุ้มครอง เป็นการสร้างตัวเลือกของฉบับเดียวกัน
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### หยุดและย้ายกลับ
หยุดเซอร์เวอร์ของ Minecraft อย่างปกติ และทําสํารองก่อนที่คุณจะเพิ่มโปรแกรม
{% endstep %}
{% step %}
<a id="install"></a>
#### ติดตั้ง
วาง MRK Doctor JAR ในตู้ `plugins/` ของเซอร์เวอร์ของคุณ และถอดคอมพิวเตอร์เก่าจากตู้นั้น
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### เริ่มและตรวจสอบ
เริ่มเปิดเซอร์เวอร์ ยืนยันว่าไม่มีความผิดพลาดในการเริ่มต้น MRK Doctor แล้วเปิด `/doctor status` เป็นผู้ประกอบการ หรือจากเครื่องปรับมือ ให้เวลาในการวัดครั้งแรก
{% endstep %}
{% endstepper %}

ต่อไปกับ [เริ่มเร็ว](quick-start.md)อย่าใช้เครื่องบรรทุกไฟฟ้าฮอตในการติดตั้งหรือเปลี่ยน MRK Doctor
