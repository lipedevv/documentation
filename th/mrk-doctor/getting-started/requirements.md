# ความต้องการ

ฉบับมหาชนเป้าหมายเซอร์เวอร์ที่เข้ากับ Bukkit จาก Minecraft **1.8.9 ถึง 26.2**ใช้เวอร์ชั่น Java ที่ต้องการจากโปรแกรมเซอร์เวอร์ของคุณ รักษาเซอร์เวอร์และการติดตั้ง Java ของคุณที่สนับสนุนโดยผู้จัดจําหน่ายของพวกเขา

การพิมพ์แบบพิมพ์ที่อุดมสมบูรณ์แบบ เป็นการพัฒนาแบบแยกสําหรับ **Paper 1.21.x กับ Java 21**. มันไม่ใช่การพัฒนาสําหรับเซอร์เวอร์เก่า หรือ Paper 26.2.

{% hint style="warning" %}
โกตั้งแค่ MRK Doctor JAR รายเดียว ไม่เคยติดตั้ง Universal และ Optimized Paper Edition รวมทั้งสําเนาที่คุ้มครองและไม่คุ้มกัน
{% endhint %}

ไม่ต้องใช้ Plugin เพิ่มเติม เพียงแค่ปล่อยพื้นที่บนดิสค์ที่พอสําหรับประวัติการตรวจโรคและรายงานส่งออก

การวัดบางครั้งอาจไม่ได้มีอยู่บนเวอร์ชั่นเซอร์เวอร์ทุกตัว การวัดที่ไม่ได้มีอยู่ไม่ได้หมายความว่าเซอร์เวอร์ของคุณมีสุขภาพดีหรือเสียหาย

แดชบอร์ดเว็บถูกเติมเข้าใน Plugin JAR การเข้าใช้งานระยะไกลต้องมีการจัดสรรการรับใช้งานที่เหมาะสม และที่อยู่เว็บที่ปลอดภัย หรือตัวแทนกลับ ดูการตั้งค่า แดชบอร์ด [dashboard setup](../dashboard/initial-setup.md)
