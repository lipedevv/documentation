# ยินดีต้อนรับ

MRK Doctor ช่วยผู้บริหารเซอร์เวอร์สืบสวนความช้า, ความผิดพลาดของ Plugin และการเปลี่ยนแปลงที่ไม่คาดหวัง

คุณสามารถดูสุขภาพเซอร์เวอร์, ตรวจสอบเหตุการณ์, ตรวจสอบการเปลี่ยนแปลงล่าสุด, ตรวจสอบอนุญาตผู้เล่น, และสร้างรายงานการวินิจฉัย. แดชบอร์ดมีอินเตอร์เฟซเว็บสําหรับการตรวจสอบข้อมูลที่มีในฉบับของคุณ.

เริ่มจากการติดตั้ง [installation](installation.md)จากนั้นทําตาม [เริ่มเร็ว](quick-start.md)

{% hint style="info" %}
เหตุผลที่น่าสงสัยเป็นตัวเบาะในการสอบสวน ไม่ใช่หลักฐานว่า Plugin มีความผิด
{% endhint %}
