# ปรับปรุง

1. รับรองเซอร์เวอร์ และตั๋ว `plugins/MRKDoctor/` หมด
2. หยุดเซอร์เวอร์ปกติ
3. แทน JAR เก่ากับการออกใหม่ของฉบับเดียวกันเก็บเพียงสําเนาเดียว
4. ตรวจสอบบันทึกการปล่อยและเปรียบเทียบการตั้งค่าที่ให้กับการตั้งค่าที่มีอยู่
5. เริ่มเซอร์เวอร์ และตรวจสอบ `/doctor status`, แดชบอร์ด, และคอนโซล

{% hint style="warning" %}
การถ่ายฉากตรวจสอบไม่ใช่สํารอง อย่าคิดว่าตัวเลือกการตั้งค่าที่หายไปจะเพิ่มขึ้นในไฟล์ที่มีอยู่โดยอัตโนมัติ
{% endhint %}
