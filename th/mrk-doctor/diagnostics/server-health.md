# ตรวจสอบสุขภาพเซอร์เวอร์

เปิด `/doctor status` หรือเปิดดัชบอร์ด ตรวจสอบสถานการณ์สุขภาพที่แสดง พร้อมกับรายงานผู้เล่น การทําความสําเร็จปัจจุบัน การใช้ความจํา และเหตุการณ์เปิด

คะแนนต่ํากว่าหมายความว่าเซอร์เวอร์ต้องการความสนใจ มันไม่สามารถระบุ plugin ที่ผิดด้วยตนเอง

การวัดบางครั้งไม่ได้มีอยู่ในเวอร์ชั่นเซอร์เวอร์เก่าๆ ลองตรวจสอบเครื่องมือการทํางานที่รองรับของเซอร์เวอร์ของคุณ หากต้องการรายละเอียดเพิ่มเติม

สําหรับปัญหาที่มีประสิทธิภาพ ติดตาม [สืบสวนเหตุการณ์](incident-investigation.md)
