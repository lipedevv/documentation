# สร้างและแบ่งปันรายงาน

เปิด `/doctor report` ในฐานะผู้ประกอบการหรือสมาชิกบุคลากรกับ `mrkdoctor.report`. รอถึงข้อความเสร็จแล้วเปิดไฟล์ที่รายงานจาก `plugins/MRKDoctor/reports/`

ฉบับมหาชนผลิตรายงาน HTML ที่สามารถเปิดได้ใน trình duyệt. ฉบับกระดาษที่อป্টিเมชั่นยังผลิตคู่มือ JSON.

ก่อนแบ่งปัน:

1. อ่านรายงานทั้งหมด และลบข้อมูลที่ไม่เกี่ยวข้อง
2. ค้นหาข้อมูลบัตรประชาชน ที่อยู่ส่วนตัว ทางไฟล์ รายละเอียดผู้เล่น และค่าการตั้งค่าที่มีความละเอียด
3. แบ่งปันข้อมูลที่จําเป็น เพียงเพื่อการสืบสวนปัญหา
4. ใช้จุดหมายสนับสนุนที่ได้รับการตรวจสอบ

{% hint style="danger" %}
การปิดบังอัตโนมัติ ไม่รับประกันว่ารายงานไม่มีความลับ คุณต้องตรวจสอบมันเอง คุณต้องหมุนข้อมูลที่ถูกเปิดเผย
{% endhint %}
