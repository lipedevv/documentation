# รอบวิจารณ์การเปลี่ยนแปลงล่าสุด

วิ่ง `/doctor changes` หรือใช้ดัชบอร์ดเพื่อดูการเปลี่ยนแปลงของ Plugin และการปรับปรุงที่มีอยู่. `/doctor timeline` ปัจจุบันแสดงรายการการเปลี่ยนแปลงล่าสุดเดียวกันในฉบับ Universal.

เปรียบเทียบเวลากับปัญหาที่รายงาน การเปลี่ยนแปลงที่เกิดขึ้นใกล้เหตุการณ์ เป็นสภาพที่ใช้ได้ แต่ไม่พิสูจน์ว่ามันเป็นสาเหตุของปัญหา

MRK Doctor ไม่ดูทุกไฟล์ หรือเปลี่ยนระบบสํารองภายนอก เพื่อยกเลิกการเปลี่ยนแปลง หยุดเซอร์เวอร์ และปฏิบัติตามวิธีการฟื้นฟูที่ได้รับการสนับสนุนจากผู้จัดส่งโปรแกรมพลูเกนที่ได้รับผลกระทบ โดยใช้สํารองของคุณเอง

การติดตามการเปลี่ยนแปลงสามารถเปิดหรือปิดในระบบ [configuration](../configuration/overview.md)
