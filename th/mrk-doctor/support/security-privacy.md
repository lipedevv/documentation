# ข้อมูลและความเป็นส่วนตัว

MRK Doctor รวบรวมข้อมูลการวินิจฉัยเกี่ยวกับเซอร์เวอร์ของคุณ ความประกอบการ ความผิดพลาด และการเปลี่ยนแปลงที่ติดตาม โดยการทํางานมาตรฐานของ MRK Doctor จะเก็บประวัติการวินิจฉัยในพื้นที่ และไม่จําเป็นต้องใช้บริการวิเคราะห์ภายนอก

ไฟล์ตรวจสอบและการเข้าถึงดัชบอร์ดสามารถเปิดเผยรายละเอียดเซอร์เวอร์, เส้นทาง, การตั้งค่า plugin หรือข้อมูลที่เกี่ยวข้องกับผู้เล่น จํากัดการเข้าถึงผู้บริหารที่เชื่อถือ, ตรวจสอบการส่งออกก่อนการแบ่งปัน, และเก็บเพียงสิ่งที่คุณต้องการ

กองสํารองแฟ้มข้อมูลทั้งหมด ก่อนการดูแล หากมีอัตราการรับรอง เปลี่ยนมันทันที

สําหรับการมีนโยบายทางกฎหมายของเว็บไซต์, ดู [ความเป็นส่วนตัว](../../privacy.md). ติดตาม [ปลอดภัยดัชบอร์ด](../dashboard/security.md) สําหรับการเข้าถึงทางไกล.
