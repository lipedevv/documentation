<a id="troubleshooting"></a>
# การแก้ปัญหา

<a id="plugin-will-not-start"></a>
## Plugin จะไม่เริ่ม

ยืนยันว่าคุณติดตั้งฉบับที่ถูกต้อง และมี MRK Doctor JAR เดียว ตรวจสอบความต้องการ Java ของเซอร์เวอร์, พื้นที่ใช้บนดิสค์ว่าง, ความอนุญาตไฟล์ และความผิดพลาดคอนโซลที่เกี่ยวข้องแรก. กรอกแบบปกติหลังจากแก้ไขปัญหา

<a id="server-is-lagging-or-shows-errors"></a>
## เซอร์เวอร์กําลังช้าหรือแสดงความผิดพลาด

จัดบันทึกเมื่อปัญหาเริ่มขึ้น ตรวจสอบ `/doctor status`, เหตุการณ์เปิด และการเปลี่ยนแปลงล่าสุด ตรวจสอบความผิดพลาดของเครื่องปรับปรุงที่ได้รับผลกระทบ, จากนั้น [สร้างรายงาน](../reports/creating-reports.md)ทดสอบการเปลี่ยนแปลงที่สามารถกลับได้ครั้งละครั้ง โดยใช้สํารอง

<a id="dashboard-will-not-connect"></a>
## แดชบอร์ดจะไม่เชื่อมต่อ

ยืนยันว่า MRK Doctor ได้เปิด และเปิดที่อยู่ของดัชบอร์ดที่ตั้งค่าตั้งค่า. ตรวจสอบที่อยู่ของบิด, การจัดจําหน่ายการรับใช้งานครั้งเดียว, ปรางไฟ, เส้นทางตัวแทน, และร่องก้าวที่ตั้งค่าตั้งค่า. ท็อกเน้นใหม่ถูกสร้างให้ใช้งานทันที. ไม่เคยปิดความปลอดภัย หรือเปิดร่องก้าวที่ไม่จํากัดเป็นทางแก้ไข.

<a id="a-player-cannot-use-a-command"></a>
## นักเล่นไม่สามารถใช้คําสั่ง

ตรวจสอบคําสั่งแม่นยํา, การอนุญาตของผู้เล่น, ข้อจํากัดโลก, และการตั้งค่าของ Plugin เจ้าของ. ติดตามการตรวจสอบอนุญาต [permission checks](../permissions/permission-doctor.md)

<a id="memory-keeps-increasing"></a>
## ความจําเพิ่มขึ้น

ติดตามการใช้งานในระยะเวลาและเปรียบเทียบกับกิจกรรมของผู้เล่น การอ่านสูงหนึ่งไม่ได้เป็นหลักฐานของการล็อกหรือการเป็นเจ้าของโปรแกรม. ใช้เครื่องมือการทําโปรไฟล์ที่สนับสนุนของเซอร์เวอร์ของคุณเมื่อต้องการรายละเอียดเพิ่มเติม.

<a id="reports-or-history-are-unavailable"></a>
## รายงานหรือประวัติไม่ได้

ตรวจสอบพื้นที่ดิสก์ว่างและอนุญาตอ่าน / เขียนสําหรับ `plugins/MRKDoctor/`. หยุดเซอร์เวอร์และสํารองโฟลเดอร์ครบ ก่อนพยายามซ่อม. อย่าลบไฟล์ข้อมูลเพื่อแก้ไขปัญหาโดยไม่ต้องสํารองที่ยืนยัน.

<a id="monitoring-overhead-seems-high"></a>
## รายจ่ายการติดตามดูสูง

ย้อนช่วงระยะการติดตามกลับสู่ช่วงเดิม, หลีกเลี่ยงการติดตามไฟล์テキストขนาดใหญ่ไม่จําเป็น, และเปรียบเทียบการทํางานภายใต้ภาระคล้าย ๆ. หากมันยังคงอยู่, ส่งบันทึกและการตั้งค่าที่เกี่ยวข้องผ่าน [การสนับสนุน](../../support.md), โดยไม่ต้องมีอัตราฐาน.
