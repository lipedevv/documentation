# การตั้งค่า

เบอร์นิชั่นนี้ครอบคลุม `plugins/MRKDoctor/config.yml` ในการตีพิมพ์มหาชน. เริ่มใหม่หลังจากการแก้ไข เว้นแต่คุณได้ตรวจสอบการพฤติกรรมการโหลดใหม่ของการตั้งค่า

| การตั้ง | ปกติ | ประสงค์ |
| --- | --- | --- |
| `doctor.server-id` | `standalone` | แผนที่ใช้สําหรับเซอร์เวอร์นี้ |
| `doctor.performance.healthy-sample-seconds` | `15` | ระยะเวลาติดตามระหว่างการทํางานปกติ |
| `doctor.performance.incident-sample-seconds` | `5` | ระยะเวลาติดตามระหว่างเหตุการณ์ |
| `doctor.changes.enabled` | `true` | ให้ติดตามการเปลี่ยนแปลงล่าสุด |
| `doctor.changes.interval-seconds` | `30` | ระยะเวลาตรวจสอบการเปลี่ยนแปลง ใช้อย่างน้อย 10 วินาที |
| `doctor.changes.max-file-bytes` | `1048576` | ขนาดจํากัดสําหรับการเปรียบเทียบรายละเอียดของไฟล์テキスト |
| `doctor.dashboard.enabled` | `true` | เปิดการเชื่อมต่อดัชบอร์ด |
| `doctor.dashboard.bind` | `0.0.0.0` | ฟังการจัดสรรเซอร์เวอร์ ใช้ `127.0.0.1` เมื่อการเข้าใช้งานต้องผ่านตัวแทนกลับของเจ้าภาพเดียวกัน |
| `doctor.dashboard.port` | `7854` | ปอร์ตเดียวที่ใช้โดยดัชบอร์ดที่ติดตั้งและ API ที่ได้รับการยืนยัน |
| `doctor.dashboard.cors-origin` | `http://127.0.0.1:7854` | การออกแบบที่อนุญาตให้เลือกสําหรับการพัฒนาตัวแทนที่ผ่านมา การเข้าใช้งานที่มาจากเดิม ไม่จําเป็นต้องมีที่อยู่หน้าต่างที่แยก |
| `doctor.dashboard.token-hash` | เบาๆ | การจัดการโดย `/doctor dashboard setup`; ไม่ต้องแก้ไขด้วยมือ |
| `storage.raw-retention-hours` | `24` | ระยะเวลาเก็บข้อมูลสําหรับประวัติเมตรละเอียด |
| `logging.debug` | `false` | ปล่อยตามการกําหนดมันไม่ได้เปิดให้มีการบันทึกเพิ่มเติมในการปล่อยนี้ |

ใช้ช่วงระยะติดตามทางดีและรั้วดัชบอร์ดที่เหมาะสม ลดช่วงระยะระยะเพิ่มงานติดตาม การทดสอบการเปลี่ยนแปลงบนเซอร์เวอร์การจัดสเตจ

{% hint style="warning" %}
อย่าติดเครื่องหมายดัชบอร์ดในตัวอย่างการตั้งค่า สร้างอ้างอิงผ่านคําสั่ง และปกป้องร่องทางการตรวจสอบ
{% endhint %}
