# คําสั่ง

ทุกคําสั่งต้อง `mrkdoctor.view`. การอนุญาตโดย मुलभूतให้กับผู้ปฏิบัติการ ดูอนุญาต [permissions](permissions.md) ก่อนมอบหมายการเข้า

| กองบัญชาการ | ใช้งาน | การอนุญาตเพิ่มเติม |
| --- | --- | --- |
| `/doctor` | เปิดภาพรวมในเกม; แสดงสถานะในเกม console | — |
| `/doctor status` | แสดงข้อมูลสุขภาพและเวลาทํางาน | — |
| `/doctor health` | แสดงสรุปสุขภาพเดียวกัน | — |
| `/doctor incidents` | รายการเหตุการณ์ที่เปิด | — |
| `/doctor changes` | แสดงการเปลี่ยนแปลงที่ติดตามล่าสุด | — |
| `/doctor timeline` | แสดงรายการการเปลี่ยนแปลงล่าสุดใน Universal | — |
| `/หมออนุญาต <player> <node>` |ตรวจสอบอนุญาตผู้เล่นออนไลน์ | — |
| `/หมอสั่ง <player> <command>` |ตรวจสอบเจ้าของคําสั่งและการเข้าถึง | — |
| `/doctor snapshot` | เก็บภาพการตรวจสอบ | — |
| `/doctor report` | สร้างไฟล์รายงาน | `mrkdoctor.report` |
| `/doctor dashboard` | แสดงที่อยู่ของดัชบอร์ดที่ตั้งค่า | `mrkdoctor.dashboard` |
| `/doctor dashboard setup` | สร้างและเปิดตัวทันทีใบรับรองดัชบอร์ดใหม่ | `mrkdoctor.dashboard` |
| `/doctor reload` | รีโหลดค่าการตั้งค่า; การเปลี่ยนแปลงบางครั้งยังต้องเริ่มใหม่ | `mrkdoctor.admin` |

ใช้ชื่อผู้เล่นออนไลน์แม่นยําในการตรวจสอบผู้เล่น ที่อยู่ที่พิมพ์โดย `/doctor dashboard` ใช้ที่อยู่การเชื่อมต่อที่ตั้ง; แทน `127.0.0.1` หรือ `0.0.0.0` ด้วยชื่อผู้จัดการสาธารณะเมื่อเปิดมันไกล

การออกแบบ Paper ที่ถูกอป্টিมิสเตอร์แล้ว ยังมี Plugin `/doctor <plugin>` สําหรับการสรุปของ Plugin คําสั่งนี้ไม่ได้มีใน Universal

`/doctor trace` แสดงเพียงแจ้งการมีในฉบับนี้; มันไม่ได้เริ่มต้นการติดตาม ไม่มีการอัพเดทหรือคําสั่งการย้อนกลับอัตโนมัติ
