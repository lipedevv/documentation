# ความปลอดภัยของดัชบอร์ด

- แบ่งปันการเข้าใช้งานกับผู้บริหารที่เชื่อถือเท่านั้น
- ใช้ HTTPS สําหรับดัชบอร์ดเว็บ และเชื่อมต่อที่ปลอดภัยกับบริการของมัน
- รักษาการเชื่อมต่อส่วนตัวตามปกติ เมื่อบริการทํางานบนเจ้าภาพเดียวกัน
- ป้องกันการจัดสรรที่อํานวยความสะดวกด้วย firewall และกฎ proxy
- แหมวนท็อกด้วย `/doctor dashboard setup` หากถูกเปิดเผย การเปลี่ยนเป็นกิจกรรมได้ทันที
- รีวิวรายงานและภาพจอ ก่อนส่งมันไปยังใคร

ไม่เคยติดเครื่องหมายดัชบอร์ดในปัญหาการสาธารณะ, ช่อง Discord, หรือตัวอย่างการตั้งค่า หากคุณไม่ต้องการการเข้าถึงเว็บ, ปิด `doctor.dashboard.enabled` และเริ่มใหม่
