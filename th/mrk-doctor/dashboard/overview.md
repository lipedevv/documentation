# แดชบอร์ด

แดชบอร์ดจะให้คุณดูสุขภาพเซอร์เวอร์, เหตุการณ์, การเปลี่ยนแปลง, และข้อมูลการตรวจโรคอื่น ๆ ที่มีในฉบับของคุณ

แดชบอร์ดครบครันถูกเติมลงใน Plugin JAR และบริการจากท่าทางดัชบอร์ดที่ตั้งค่า ไม่จําเป็นต้องมี Node.js หรือ Next.js เป็นที่แยกกัน เลือกการจัดสรรที่ว่างในกรอบการจัดสรรของคุณและปฏิบัติตามการตั้งตัวแรก [initial setup](initial-setup.md)

ระวังการเข้าถึงจํากัดให้กับผู้บริหารที่เชื่อถือ อย่าใส่ข้อมูลของดัชบอร์ดในภาพจอหรือข้อความสนับสนุนสาธารณะ

หากหน้าเปิด แต่ไม่เชื่อมต่อ ติดตาม [แก้ปัญหา](../support/troubleshooting.md#dashboard-will-not-connect)
