# Pterodactyl บริการรับใช้งาน

เลือกการจัดสรรที่ว่างในกรอบเซอร์เวอร์ของคุณ เช่น `7854`และตั้ง `doctor.dashboard.port` ให้เข้าสู่ท่าเรือนั้น ไม่จําเป็นต้องใช้การจัดสรรที่แยกทางเว็บ หรือการจัดสรรที่สอง

ใช้ที่อยู่บิดที่ต้องการจากเครือข่ายการจัดเก็บของคุณ ที่อยู่ของ Localhost ของคอนเทนเนอร์ไม่สามารถเข้าถึงได้จากคอนเทนเนอร์ที่แยก หากเจ้าของใช้ `0.0.0.0`ให้แน่ใจว่าการจัดสรรถูกคุ้มครองโดยไฟวอลล์หรือตัวแทนที่ปลอดภัย ก่อนเปิดการเข้าถึง

แดชบอร์ดเว็บถูกบริการโดยตรงโดย Plugin. ติดตามการตั้งตัวแรก [initial setup](initial-setup.md), restart หลังจากเปลี่ยนที่อยู่บิดหรือปอร์ต, และทดสอบหน้าโดยใช้ที่อยู่ที่ได้รับมอบ.

{% hint style="warning" %}
อย่าเปิดท่าเรือที่ไม่จํากัดเพื่อแก้ปัญหาการเชื่อมต่อ หากแผนของคุณไม่อนุญาตให้คุณเลือกหรือเปิดการจัดสรร, ภายในระบบการรับใช้งานมีเพียงผู้ให้บริการรับใช้งานเท่านั้นที่สามารถทําท่าเรือในตู้ดช็อปเข้าได้; ปล็อตไม่สามารถข้ามไฟฟาร์มาวอลของผู้รับใช้งานได้
{% endhint %}
