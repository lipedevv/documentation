# การตั้งค่า

ปรับ `plugins/MRKDoctor/config.yml` ด้วยเครื่องแก้วข้อความ YAML รู้จัก ทําสํารองก่อนและรักษาการบันทึก

การตั้งค่าโดยปกติ เป็นจุดเริ่มต้นที่ดี เพียงแค่เปลี่ยนการตั้งค่าที่คุณต้องการ เช่น แผนเซอร์เวอร์ ระยะเวลาการติดตาม การเข้าสู่ดัชบอร์ด หรือการเก็บประวัติศาสตร์

การรับรอง Dashboard ที่สร้างโดย `/doctor dashboard setup` จะเริ่มใช้ได้ทันที. การเริ่มต้นใหม่หลังจากที่เปลี่ยนที่อยู่บิด, ท่าเรือ, สถานที่เปิดให้ใช้ หรือ การตั้งค่าการติดตาม. `/doctor reload` ไม่แทนการเริ่มใหม่เต็มสําหรับการเปลี่ยนแปลงเชื่อมต่อและรอบชีวิตเหล่านั้น.

ใช้ [การตั้งค่า](../reference/configuration.md) สําหรับการออกแบบมหาชน อย่าสําเนาการตั้งค่าเพิ่มเติมจากการออกแบบอื่น และคาดว่าจะเปิดให้มีคุณสมบัติใหม่
