# การสนับสนุน

เริ่มด้วยการแก้ไขปัญหา [troubleshooting](mrk-doctor/support/troubleshooting.md)หากคุณต้องการความช่วยเหลือ เตรียม:

- เวอร์ชั่นโปรแกรม Minecraft/เซอร์เวอร์ และเวอร์ชั่น Java
- รุ่นและฉบับ MRK Doctor
- เกิดอะไรขึ้น เมื่อเกิดอะไรขึ้น และวิธีการนํามันกลับคืนมา
- ความผิดพลาดที่เกี่ยวข้องของเครื่องปรับปรุง และรายงานการตรวจสอบ

อย่าส่งท็อกน์ดัชบอร์ด ปัสริด ไฟล์การตั้งค่าส่วนตัวเต็ม หรือข้อมูลผู้เล่นที่ไม่เกี่ยวข้อง

ส งสนับสนุนทางการยังไม่ได้จัดส่ง ใช้จุดหมายสนับสนุนที่ตรวจสอบที่เกี่ยวข้องกับการซื้อของคุณ อย่าส่งไฟล์ไปยังบัญชีที่ไม่ได้ตรวจสอบ
