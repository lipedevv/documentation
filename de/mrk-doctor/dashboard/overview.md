# Das Dashboard

Das Dashboard ermöglicht es Ihnen, die Gesundheit des Servers, Vorfälle, Änderungen und andere diagnostische Informationen in Ihrer Ausgabe zu überprüfen.

Das komplette Dashboard ist im Plugin JAR eingebettet und vom konfigurierten Dashboard-Port bedient. Es ist kein separates Node.js oder Next.js -Hosting erforderlich. Wählen Sie eine verfügbare Zuweisung in Ihrem Hosting-Panel aus und folgen Sie der [-Initial-Einstellung](initial-setup.md).

Zugriff auf vertrauenswürdige Administratoren ist eingeschränkt.

Wenn sich die Seite öffnet, aber nicht verbunden wird, folgen Sie [Fehlerbehebung](../support/troubleshooting.md#dashboard-will-not-connect).
