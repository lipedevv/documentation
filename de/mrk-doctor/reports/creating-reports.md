# Erstellen und teilen Sie einen Bericht

Laufen Sie `/doctor report` als Betreiber oder Mitarbeiter mit `mrkdoctor.report`aus . Warten Sie auf die Nachricht und öffnen Sie die gemeldete Datei von `plugins/MRKDoctor/reports/`.

Die Universal-Edition erzeugt einen HTML-Bericht, der in einem Browser geöffnet werden kann.

Vor dem Teilen:

1. Lesen Sie den vollständigen Bericht und entfernen Sie unabhängige Informationen.
2. Suchen Sie nach Anmeldeinformationen, privaten Adressen, Dateipfaden, Spielerdaten und sensiblen Konfigurationswerten.
3. Geben Sie nur die Informationen an, die zur Untersuchung des Problems erforderlich sind.
4. Verwenden Sie ein verifiziertes Support-Destination.

{% hint style="danger" %}
Die automatische Maskierung garantiert nicht, dass ein Bericht keine Geheimnisse enthält.
{% endhint %}

Include your Minecraft version, MRK Doctor version, a short description, reproduction steps, and the time the problem occurred. See [support](../../support.md).
