# Erforschung eines Problems

1. Bestätigen Sie, was die Spieler erleben und beachten Sie, wann es begann.
2. Führen Sie `/doctor status` und `/doctor incidents`aus .
3. Öffnen Sie den Vorfall im Dashboard und lesen Sie die Details und Vorschläge.
4. Vergleichen Sie die Zeit mit [jüngsten Änderungen](../changes/change-tracker.md).
5. Lesen Sie relevante Konsolenfehler und überprüfen Sie die eigene Dokumentation des betroffenen Plugins.
6. Speichern Sie einen [-Bericht](../reports/creating-reports.md) vor dem Wechsel des Servers.
7. Zurück, machen Sie eine umkehrbare Änderung und beobachten Sie das Ergebnis.

{% hint style="warning" %}
Behandeln Sie ein verdächtigtes Plugin und alle Vertrauensangaben als Untersuchungsanleitung, nicht als Garantie. MRK Doctor führt keine Reparaturen, Plugin-Updates oder Rückführung durch.
{% endhint %}
