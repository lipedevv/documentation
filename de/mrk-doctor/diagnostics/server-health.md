# Überprüfen Sie den Serverzustand

Laufen Sie `/doctor status` aus oder öffnen Sie das Dashboard. Überprüfen Sie den angezeigten Gesundheitszustand zusammen mit den Spielerberichten, aktuellen Leistungen, Speicherverbrauch und offenen Vorfällen.

Eine niedrigere Punktzahl bedeutet, dass der Server Aufmerksamkeit braucht; er identifiziert kein schuldiges Plugin allein. Vergleiche Lesungen im Laufe der Zeit, anstatt aus einem Moment eine Schlussfolgerung zu ziehen.

Einige Messungen sind auf älteren Serverversionen nicht verfügbar. Überprüfen Sie die Konsole und verwenden Sie die unterstützten Leistungswerkzeuge Ihres Servers, wenn weitere Details erforderlich sind.

Für ein aktives Problem folgen Sie [, untersuchen Sie einen Vorfall](incident-investigation.md).
