# Anforderungen

Die Universal Edition zielt auf Bukkit-kompatible Server von Minecraft **1.8.9 bis 26.2**ab. Verwenden Sie die Java-Version, die von Ihrer Serversoftware benötigt wird. Halten Sie Ihren Server und Java-Installation von ihren jeweiligen Anbietern unterstützt.

Die optimierte Paper-Edition ist ein separates Build für **Paper 1.21.x mit Java 21**. Es ist nicht das Build für ältere Server oder Paper 26.2.

{% hint style="warning" %}
Installieren Sie nur einen MRK-Doktor-JAR.
{% endhint %}

Es ist nicht erforderlich, dass ein zusätzliches Plugin verwendet wird.

Einige Messungen sind möglicherweise nicht auf jeder Serverversion verfügbar.

Das Web-Dashboard ist im Plugin JAR eingebettet. Fernzugriff erfordert eine geeignete Hosting-Zuteilung und eine sichere Web-Adresse oder einen umgekehrten Proxy. Siehe [Dashboard-Setup](../dashboard/initial-setup.md).
