# Aktualisierung

1. Sicherung des Servers und des kompletten `plugins/MRKDoctor/` -Ordners.
2. - Stehen Sie den Server normal ab.
3. Ersetzen Sie die alte JAR durch die neue Ausgabe derselben Ausgabe.
4. Überprüfen Sie die Release-Noten und vergleichen Sie die bereitgestellte Konfiguration mit Ihren bestehenden Einstellungen.
5. Starten Sie den Server und überprüfen Sie `/doctor status`, das Dashboard und die Konsole.

{% hint style="warning" %}
Ein Diagnoseschnappschuss ist kein Backup. Nehmen Sie nicht an, dass fehlende Konfigurationsoptionen automatisch einer vorhandenen Datei hinzugefügt werden.
{% endhint %}
