# Installation

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Wählen Sie Ihre Akte aus
Die JARs, die geschützt und ungeschützt sind, sind alternative Versionen derselben Edition.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Haltet auf und zurück .
Stoppen Sie den Minecraft-Server normal und machen Sie eine Sicherung, bevor Sie das Plugin hinzufügen.
{% endstep %}
{% step %}
<a id="install"></a>
#### Installation
Stellen Sie einen MRK Doctor JAR in den `plugins/` -Ordner Ihres Servers und entfernen Sie ältere Kopien aus diesem Ordner.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Beginnen und überprüfen
Starten Sie den Server. Bestätigen Sie, dass keine MRK-Doktor-Startfehler vorliegen, und laufen Sie `/doctor status` als Operator oder von der Konsole aus.
{% endstep %}
{% endstepper %}

Weiter mit [Schnellstart](quick-start.md). Verwenden Sie keine Plugin-Hot-Loader, um MRK Doctor zu installieren oder zu ersetzen.
