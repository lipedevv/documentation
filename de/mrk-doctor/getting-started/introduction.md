# Willkommen .

MRK Doctor hilft Serveradministratoren, Verzögerungen, Pluginfehler und unerwartete Änderungen zu untersuchen.

Sie können die Gesundheitslage des Servers anzeigen, Vorfälle überprüfen, aktuelle Änderungen überprüfen, die Zugriffe des Spielers überprüfen und diagnostische Berichte erstellen.

Beginnen Sie mit der Installation von [installation](installation.md), und folgen Sie dann dem [Schnellstart](quick-start.md).

{% hint style="info" %}
Eine vermutete Ursache ist ein Hinweis, um zu untersuchen, nicht ein Beweis dafür, dass ein Plugin schuldig ist. MRK Doctor repariert Ihren Server nicht automatisch oder rückläuft ihn nicht.
{% endhint %}
