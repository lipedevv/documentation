# Schnell anfangen

1. Führen Sie `/doctor status` aus, um den aktuellen Serverzustand zu überprüfen.
2. Laufen Sie `/doctor` aus, um die Übersicht zu öffnen.
3. Führen Sie `/doctor incidents` aus, um offene Probleme zu sehen.
4. Führen Sie `/doctor changes` aus, um die jüngsten verfolgten Änderungen zu überprüfen.
5. Verwenden Sie `/doctor report` , wenn Sie einen Bericht für Unterstützung benötigen.

Die ersten Messungen dauern nach dem Start vielleicht etwas Zeit.

For web access, follow [dashboard setup](../dashboard/initial-setup.md). For a problem already affecting players, open [troubleshooting](../support/troubleshooting.md).
