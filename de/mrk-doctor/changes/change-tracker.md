# Überprüfung der jüngsten Änderungen

Laufen Sie `/doctor changes` aus oder verwenden Sie das Dashboard, um verfügbare Plugin- und Konfigurationsänderungen zu überprüfen. `/doctor timeline` zeigt derzeit die gleiche Liste der jüngsten Änderungen in der Universal-Edition an.

Vergleichen Sie Zeitstempel mit dem gemeldeten Problem. Eine Veränderung, die in der Nähe eines Vorfalls auftritt, ist ein nützlicher Kontext, beweist aber nicht, dass sie das Problem verursacht hat.

MRK Doctor überwacht nicht jede Datei oder ersetzt ein externes Backup-System. Um eine Änderung zu unzulässen, stoppen Sie den Server und folgen Sie dem unterstützten Wiederherstellungsverfahren des betroffenen Plugin-Anbieters mit Ihrem eigenen Backup.

Change tracking can be enabled or disabled in [configuration](../configuration/overview.md).
