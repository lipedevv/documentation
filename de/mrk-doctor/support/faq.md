# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## Behebt der MRK-Arzt Probleme automatisch?

Nein, es bietet Diagnostik, um Ihnen zu helfen, einen sicheren nächsten Schritt zu wählen.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## Ist ein verdächtiger Plugin definitiv verantwortlich?

Überprüfen Sie das Problem, bevor Sie ein Plugin beschuldigen, entfernen oder ersetzen.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## Kann ich das Dashboard sofort benutzen, nachdem ich die JAR kopiert habe?

Ja. Die Dashboard-Anwendung ist in das Plugin JAR eingebettet. Erstellen Sie ein Token, konfigurieren Sie einen erreichbaren Port und folgen Sie der [-Verbindungsanordnung](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## Ist ein Diagnoseschnappschuss ein Backup?

Nein, behalte separate Backups von Welten, Plugin-Dateien, Konfiguration und Daten.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## Soll ich beide Ausgaben oder beide Schutzvarianten installieren?

Installieren Sie nur eine kompatible JAR.

<a id="can-i-share-reports-without-reviewing-them"></a>
## Kann ich Berichte teilen, ohne sie zu überprüfen?

Nein, überprüfen Sie immer, ob sensible Informationen aufgetragen werden, auch wenn automatische Masken eingesetzt wurden.
