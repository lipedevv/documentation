# Speichern Sie einen Diagnoseschnappschuss

Führen Sie `/doctor snapshot`aus . Der Befehl meldet den Weg der erzeugten Datei in `plugins/MRKDoctor/snapshots/`.

Bevor Sie ein Problem untersuchen oder eine Pluginkonfiguration ändern, halten Sie einen Schnappschuss auf.

{% hint style="warning" %}
Ein Snapshot ist ein diagnostisches Datensatz, nicht ein Server-Backup. Es kann Welten, Plugin-Dateien, Konfiguration oder den kompletten MRK-Doktor-Datenordner nicht wiederherstellen.
{% endhint %}
