# Thiết lập

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Chọn hồ sơ của bạn
Sử dụng JAR phổ quát trừ khi bạn đặc biệt cần phiên bản giấy tối ưu hóa.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Ngừng lại và lùi lại.
Ngừng máy chủ Minecraft bình thường và sao lưu trước khi thêm plugin.
{% endstep %}
{% step %}
<a id="install"></a>
#### Thiết lập
Đặt một MRK Doctor JAR vào thư mục `plugins/` của máy chủ của bạn.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Bắt đầu và kiểm tra
Bắt đầu máy chủ. xác nhận không có lỗi khởi động MRK Doctor, sau đó chạy `/doctor status` như một nhà điều hành hoặc từ máy điều khiển. Cho phép thời gian cho các phép đo ban đầu.
{% endstep %}
{% endstepper %}

Cứ tiếp tục với [khởi động nhanh](quick-start.md). Đừng sử dụng bộ tải nóng plugin để cài đặt hoặc thay thế MRK Doctor.
