# 최근 변화 를 검토

`/doctor changes` 를 실행하거나 사용 가능한 플러그인 및 구성 변경 사항을 검토하는 데시보드를 사용하십시오. `/doctor timeline` 는 현재 Universal 에디션에서 동일한 최근의 변경 목록을 보여줍니다.

보고된 문제와 시간표를 비교해 보십시오. 사건 근처에서 일어나는 변화는 유용한 맥락이지만, 문제가 발생했다는 것을 증명하지는 않습니다.

MRK Doctor는 모든 파일을 확인하거나 외부 백업 시스템을 교체하지 않습니다. 변경 사항을 취소하려면 서버를 중지하고 해당 플러그인 공급자의 지원 복원 절차를 따라 자신의 백업을 사용하여 변경을 취소하십시오.

변경 추적은 [구성](../configuration/overview.md)에서 활성화되거나 비활성화될 수 있습니다 .
