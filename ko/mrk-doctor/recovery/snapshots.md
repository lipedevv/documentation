# 진단 스냅샷을 저장

`/doctor snapshot`를 실행하세요 . 명령어는 `plugins/MRKDoctor/snapshots/`에서 생성된 파일의 경로를 보고합니다 .

문제점 조사 또는 플러그인 구성 변경 전에 스냅샷을 보관하고 공유하기 전에 민감한 정보를 확인하십시오.

{% hint style="warning" %}
스냅샷은 진단 기록이 아니라 서버 백업입니다. 세계, 플러그인 파일, 구성 또는 전체 MRK Doctor 데이터 폴더를 복원할 수 없습니다. 별도의 백업을 유지하십시오.
{% endhint %}
