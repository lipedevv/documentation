<a id="installation"></a>
# 설치

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### 파일 선택
최적화된 종이판이 필요 없는 한 Universal JAR를 사용하세요. 보호 및 보호되지 않은 JAR는 동일한판의 대체 빌드입니다.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### 멈추고 뒤로 물러서
Minecraft 서버를 정상적으로 중지하고 플러그인을 추가하기 전에 백업하십시오.
{% endstep %}
{% step %}
<a id="install"></a>
#### 설치
MRK Doctor JAR를 서버의 `plugins/` 폴더에 넣고 그 폴더에서 오래된 복사본을 제거하십시오.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### 시작하고 확인
서버를 시작하세요. MRK Doctor 시작 오류가 없는지 확인하고, `/doctor status` 를 운영자 또는 콘솔에서 실행하세요. 초기 측정에 시간을 허용하세요.
{% endstep %}
{% endstepper %}

[빠른 시작](quick-start.md)를 계속 사용하십시오. MRK Doctor를 설치하거나 교체하려면 플러그인 핫 로더를 사용하지 마십시오.
