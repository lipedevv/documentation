# 업데이트

1. 서버와 `plugins/MRKDoctor/` 폴더를 백업하세요.
2. 서버를 정상적으로 중지하세요.
3. 오래된 JAR를 같은 에디션의 새로운 버전으로 교체해 주세요.
4. 출력 메모를 검토하고 제공된 구성을 기존 설정과 비교하십시오.
5. 서버를 시작해서 `/doctor status`, 패시보드, 콘솔을 확인하세요.

{% hint style="warning" %}
진단 스냅샷은 백업이 아닙니다. 결실된 구성 옵션이 기존 파일에 자동으로 추가될 것이라고 가정하지 마십시오.
{% endhint %}
