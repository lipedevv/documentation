# 요구 사항

유니버설 에디션은 Minecraft **1.8.9에서 26.2**까지의 Bukkit 호환 서버를 대상으로 합니다. 서버 소프트웨어에서 요구하는 자바 버전을 사용하세요. 서버와 자바 설치가 해당 공급업체에서 지원되도록 유지하세요.

최적화된 페이퍼 에디션은 **페이퍼 1.21.x와 자바 21**의 별도의 빌드입니다. 기존 서버나 페이퍼 26.2의 빌드이 아닙니다.

{% hint style="warning" %}
MRK Doctor JAR 한 개만 설치하세요. 유니버설 및 최적화된 종이판을 함께 설치하지 마십시오. 또는 보호 및 보호되지 않은 복사본 모두 설치하지 마십시오.
{% endhint %}

추가 플러그인이 필수적이지 않습니다. 진단 역사와 수출 보고에 충분한 자유 디스크 공간을 남겨두십시오.

일부 측정은 모든 서버 버전에서 사용할 수 없을 수도 있습니다. 사용되지 않는 측정은 서버가 건강하거나 손상된 것을 의미하지는 않습니다.

웹 패시보드는 JAR 플러그인 내에 내장되어 있습니다. 원격 액세스에는 적절한 호스팅 할당과 안전한 웹 주소 또는 역 프록시가 필요합니다. [패시보드 설정](../dashboard/initial-setup.md)참조.
