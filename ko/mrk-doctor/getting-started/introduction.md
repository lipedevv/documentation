# 환영합니다

MRK Doctor는 서버 관리자가 지연, 플러그인 오류 및 예기치 않은 변경 사항을 조사하는 데 도움이됩니다.

서버 건강, 사고 확인, 최근 변경 사항을 검토, 플레이어 권한 확인 및 진단 보고서를 생성할 수 있습니다. 대시보드는 웹 인터페이스를 제공하여 에디션에 사용할 수 있는 정보를 검토합니다.

[설치부터 시작하여](installation.md)를 시작하여 [빠른 시작](quick-start.md)를 따라가십시오 .

{% hint style="info" %}
의심의 여지가 있는 원인은 플러그인이 잘못되었다는 증거가 아니라 조사의 근거입니다. MRK 의사는 자동으로 서버를 복구하거나 다시 돌리지 않습니다.
{% endhint %}
