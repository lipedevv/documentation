# 빨리 시작

1. 현재 서버 상태를 확인하기 위해 `/doctor status` 를 실행하세요.
2. 게임에서는 `/doctor` 를 실행하여 전체적인 개요를 열 수 있습니다.
3. 열린 문제를 보기 위해 `/doctor incidents` 를 실행하세요.
4. 최근 추적된 변경 사항을 검토하기 위해 `/doctor changes` 를 실행하세요.
5. 지원 보고서를 필요로 할 때 `/doctor report` 를 사용하십시오.

처음 판독은 시작 후 약간의 시간이 걸릴 수 있습니다. 새로운 설치를 판단하기 전에 서버를 실행하도록 유지하십시오.

For web access, follow [dashboard setup](../dashboard/initial-setup.md). For a problem already affecting players, open [troubleshooting](../support/troubleshooting.md).
