# 구성

YAML 인식 된 텍스트 편집기 (text editor) 를 사용하여 `plugins/MRKDoctor/config.yml` 를 편집하십시오. 먼저 백업을 수행하고 실력을 보존하십시오.

기본 설정은 좋은 출발점입니다. 서버 레이블, 모니터링 간격, 대시보드 액세스 또는 역사 저장과 같은 필요한 설정만 변경하십시오.

`/doctor dashboard setup` 에 의해 생성된 대시보드 인증서는 즉시 활성화됩니다. 연결 주소, 포트, 활성화 된 상태 또는 모니터링 설정을 변경한 후 다시 시작하십시오. `/doctor reload` 는 연결 및 라이프사이클 변경에 대한 완전한 재 시작의 대상이 아닙니다.

유니버설 에디션에 [구성 참조](../reference/configuration.md) 를 사용하십시오. 다른 에디션에서 추가 설정을 복사하지 말고 새로운 기능을 활성화 할 것이라고 가정하십시오.
