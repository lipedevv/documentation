# 서버 건강 확인

`/doctor status` 를 실행하거나 패시보드를 열고, 플레이어 보고, 현재 성능, 메모리 사용 및 오픈 인시던트와 함께 표시된 건강 상태를 검토하십시오.

낮은 점수는 서버가 주의를 필요로 한다는 것을 의미합니다. 그것은 자체적으로 죄인 플러그인을 식별하지 않습니다. 한 순간부터 결론을 내리기 보다는 시간적 판독을 비교하십시오.

이전 서버 버전에서는 일부 측정이 사용되지 않습니다. 콘솔을 확인하고 더 자세한 사항이 필요한 경우 서버의 지원된 성능 도구를 사용하십시오.

For an active problem, follow [investigate an incident](incident-investigation.md).
