# 문제 를 조사 해 보십시오

1. 플레이어가 경험하고 있는 것을 확인하고 시작했을 때를 알아보십시오.
2. `/doctor status` 와 `/doctor incidents`를 실행하세요 .
3. 현황을 래시보드에서 열고, 그 세부사항과 시사사항을 읽어보세요.
4. 시기를 [최근 변경 사항과 비교하십시오](../changes/change-tracker.md).
5. 관련 콘솔 오류를 읽고 해당 플러그인의 문서 확인
6. Save a [report](../reports/creating-reports.md) before changing the server.
7. 뒤로 물러서서, 되돌릴 수 있는 한 가지 변화를 만들어서 그 결과를 관찰해 보세요.

{% hint style="warning" %}
의심의 여지인 플러그인 및 신뢰성 표시를 조사 지침으로 취급하고 보증하지 않습니다. MRK 의사는 당신을 위해 수리, 플러그인 업데이트 또는 롤백을 수행하지 않습니다.
{% endhint %}
