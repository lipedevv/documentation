# 보고서를 작성하고 공유

Run `/doctor report` as an operator or staff member with `mrkdoctor.report`. Wait for the completion message and open the reported file from `plugins/MRKDoctor/reports/`.

유니버설 에디션은 브라우저에서 열 수 있는 HTML 보고서를 생성합니다. 최적화된 페이퍼 에디션은 JSON 동반자를 생성합니다.

공유하기 전에:

1. 전체 보고서를 읽어보고 관련 없는 정보를 제거하십시오.
2. 신분자료, 개인 주소, 파일 경로, 플레이어 세부 정보 및 민감한 구성 값을 찾으십시오.
3. 이 문제를 조사하기 위해 필요한 정보를만 공유하세요.
4. 검증된 지원 목적지를 사용하세요.

{% hint style="danger" %}
자동 마스크링은 보고서에 비밀이 없다는 것을 보장하지 않습니다. 항상 직접 검토하십시오. 노출된 모든 자격증을 회전하십시오.
{% endhint %}
