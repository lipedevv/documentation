# 대시보드 보안

- 신뢰할 수 있는 관리자와만 공유할 수 있습니다.
- 웹 패시보드에서 HTTPS를 사용하며 서비스와 안전한 연결을하십시오.
- 동일한 호스트에서 서비스를 실행할 때 기본 로컬 뱅을 유지하십시오.
- 방화벽과 프록시 규칙으로 호스팅 할당을 보호하십시오.
- 로켓을 `/doctor dashboard setup` 로 회전하면 노출됩니다. 교체 즉시 활성화됩니다.
- 보고와 스크린샷을 보고 다른 사람에게 보내기 전에 검토하세요.

공개 이슈, 디스코드 채널 또는 구성 예제에 탭표시를 붙이지 마십시오. 웹 접속이 필요하지 않으면 `doctor.dashboard.enabled` 를 비활성화하고 다시 시작하십시오.
