# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## MRK 의사가 문제를 자동으로 해결합니까?

안 됩니다. 다음 단계에 안전한 방법을 선택하는데 도움이 되는 진단도 제공합니다. 백업, 플러그인 업데이트, 복구도 여러분의 책임입니다.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## 의심되는 플러그인이 확실히 책임지는가?

문제점을 확인하기 전에 플러그인을 비난하거나 제거하거나 교체하십시오.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## JAR를 복사한 즉시 패시보드를 사용할 수 있나요?

Yes. The dashboard application is embedded in the plugin JAR. Generate a token, configure one reachable port, and follow the [connection setup](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## 진단 촬영은 백업인가요?

세계, 플러그인 파일, 구성 및 데이터의 별도의 백업을 유지하십시오.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## 두 에디션이나 두 가지 보호 변종을 설치해야 할까요?

아니, 단 하나의 호환 가능한 JAR를 설치하세요.

<a id="can-i-share-reports-without-reviewing-them"></a>
## 보고서를 검토하지 않고 보고서를 공유할 수 있나요?

아니, 자동 마스크가 적용된 경우에도 항상 민감한 정보를 확인하세요.
