# 지원

Start with [troubleshooting](mrk-doctor/support/troubleshooting.md). If you need help, prepare:

- 마인크래프트/서버 소프트웨어 버전과 자바 버전
- MRK 닥터 버전과 에디션
- 무슨 일이 일어났는지, 언제 일어났는지, 그리고 어떻게 재현해야 하는지.
- 관련 콘솔 오류와 검토된 진단 보고서를

대시보드 토큰, 비밀번호, 전체 개인 구성 파일 또는 관련 없는 플레이어 정보를 보내지 마십시오.

공식 지원 링크는 아직 제공되지 않았습니다. 구매와 관련된 확인된 지원 목적지를 사용하세요. 확인되지 않은 계정으로 파일을 전송하지 마십시오.
