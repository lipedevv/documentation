# Rivista delle recenti modifiche

Eseguire `/doctor changes` o utilizzare il pannello di controllo per rivedere i cambiamenti di plugin e configurazione disponibili. `/doctor timeline` mostra attualmente lo stesso elenco di modifiche recenti nell'edizione universale.

Un cambiamento che si verifica vicino a un incidente è un contesto utile, ma non dimostra che sia stato il motivo del problema.

MRK Doctor non controlla ogni file o sostituisce un sistema di backup esterno. Per annullare una modifica, fermare il server e seguire la procedura di recupero supportata dal fornitore di plugin interessato utilizzando il proprio backup.

Il monitoraggio dei cambiamenti può essere abilitato o disattivato nella configurazione [configuration](../configuration/overview.md).
