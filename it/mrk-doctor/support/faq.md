# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## Il medico MRK risolve i problemi automaticamente?

No, fornisce una diagnosi che ti aiuta a scegliere un'opzione sicura.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## E' un plugin sospettato il responsabile?

No, verificate il problema prima di incolpare, rimuovere o sostituire un plugin.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## Posso usare la dashboard subito dopo aver copiato la JAR?

Si. L'applicazione della dashboard è incorporata nel plugin JAR. Generare un token, configurare una porta accessibile e seguire la configurazione della connessione [connection setup](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## Un'istantanea diagnostica e' un backup?

No, conservi un backup separato dei mondi, dei file dei plugin, delle configurazioni e dei dati.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## Dovrei installare entrambe le edizioni o entrambe le varianti di protezione?

No, installa solo un JAR compatibile.

<a id="can-i-share-reports-without-reviewing-them"></a>
## Posso condividere i rapporti senza esaminarli?

Controlla sempre le informazioni sensibili, anche quando si è applicato un mascheramento automatico.
