# Salvare un'istantanea diagnostica

Eseguire `/doctor snapshot`. Il comando segnala il percorso del file generato in `plugins/MRKDoctor/snapshots/`.

Conservare un'istantanea quando si indaga su un problema o prima di cambiare la configurazione di un plugin.

{% hint style="warning" %}
Un'istantanea è un record diagnostico, non un backup del server. Non può ripristinare mondi, file di plugin, configurazione o la cartella di dati completa di MRK Doctor.
{% endhint %}
