# Controllare la salute del server

Eseguire `/doctor status` o aprire la scheda di controllo.

Un punteggio inferiore significa che il server ha bisogno di attenzione; non identifica da solo un plugin colpevole.

Alcune misure non sono disponibili su versioni precedenti del server.

Per un problema attivo, seguire [indagare un incidente](incident-investigation.md).
