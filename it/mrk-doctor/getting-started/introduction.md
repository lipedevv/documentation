# Benvenuti

MRK Doctor aiuta gli amministratori del server a indagare sul ritardo, sugli errori del plugin e sui cambiamenti inaspettati.

È possibile visualizzare la salute del server, verificare gli incidenti, rivedere le recenti modifiche, verificare le autorizzazioni dei giocatori e generare rapporti diagnostici.

Inizia con l' installazione di [installation](installation.md), quindi segui la [start rapido](quick-start.md).

{% hint style="info" %}
Una causa sospetta è una pista per indagare, non la prova che un plugin è in colpa. MRK Doctor non riparerà o rimetterà automaticamente il server.
{% endhint %}
