<a id="installation"></a>
# Installazione

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Scegli il tuo file
Utilizzare il JAR universale a meno che non si abbia specificamente bisogno dell'edizione cartacea ottimizzata.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Fermati e ritiri.
Ferma normalmente il server di Minecraft e fai un backup prima di aggiungere il plugin.
{% endstep %}
{% step %}
<a id="install"></a>
#### Installazione
Metti una MRK Doctor JAR nella cartella `plugins/` del tuo server e rimuovi le copie più vecchie da quella cartella.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Inizia e controlla
Inizia il server. Confirma che non ci sono errori di avvio di MRK Doctor, quindi esegui `/doctor status` come operatore o dalla console.
{% endstep %}
{% endstepper %}

Continuare con [inizio rapido](quick-start.md). Non utilizzare plug-in hot-loaders per installare o sostituire MRK Doctor.
