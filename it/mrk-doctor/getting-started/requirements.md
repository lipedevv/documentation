# Requisiti

L'edizione universale si rivolge ai server compatibili con Bukkit da Minecraft **1.8.9 a 26.2**. Utilizzare la versione Java richiesta dal software del server.

L' edizione Paper ottimizzata è una build separata per **Paper 1.21.x con Java 21**. Non è la build per i server legacy o Paper 26.2.

{% hint style="warning" %}
Non installare mai insieme le edizioni universali e ottimizzate di carta, o copie protette e non protette.
{% endhint %}

Nessun plugin aggiuntivo è obbligatorio. Lasciare spazio libero sufficiente sul disco per la cronologia diagnostica e i rapporti esportati.

Alcune misurazioni potrebbero non essere disponibili su tutte le versioni del server.

The web dashboard is embedded in the plugin JAR. Remote access requires one suitable hosting allocation and a secure web address or reverse proxy. See [dashboard setup](../dashboard/initial-setup.md).
