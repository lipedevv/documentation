# Inizio rapido

1. Eseguire `/doctor status` per verificare la condizione del server.
2. In gioco, eseguire `/doctor` per aprire la panoramica.
3. Eseguire `/doctor incidents` per vedere i problemi aperti.
4. Eseguire `/doctor changes` per rivedere le recenti modifiche monitorate.
5. Utilizzare `/doctor report` quando avete bisogno di un rapporto di supporto.

Le prime letture possono richiedere un po' di tempo dopo l'avvio.

Per l'accesso al web, seguire la configurazione del dashboard [dashboard setup](../dashboard/initial-setup.md). Per un problema che colpisce già i giocatori, aprire [troubleshooting](../support/troubleshooting.md).
