# Aggiornamento

1. Fare backup del server e della cartella completa `plugins/MRKDoctor/` .
2. Fermati il server normalmente.
3. Rimpiazzate il vecchio JAR con la nuova edizione della stessa edizione.
4. Rivisita le note di rilascio e confronta la configurazione fornita con le impostazioni esistenti.
5. Inizia il server e controlla `/doctor status`, la dashboard e la console.

{% hint style="warning" %}
Un'istantanea diagnostica non è un backup. Non supporre che le opzioni di configurazione mancanti verranno automaticamente aggiunte a un file esistente.
{% endhint %}
