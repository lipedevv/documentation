# Supporto

Inizia con [risolvere i problemi](mrk-doctor/support/troubleshooting.md). Se hai bisogno di aiuto, prepara:

- Versione software Minecraft/server e versione Java.
- Versione e edizione del MRK Doctor.
- Cosa e' successo, quando e come riprodurlo.
- Errori della console e un rapporto diagnostico rivisto.

Non inviare token di dashboard, password, file di configurazione privati complete o informazioni non correlate al giocatore.

I collegamenti ufficiali di supporto non sono ancora stati forniti. Utilizzare la destinazione di supporto verificata associata al tuo acquisto; non inviare file a account non verificati.
