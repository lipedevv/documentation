# Zkontrolujte stav serveru

Zobrazit `/doctor status` nebo otevřít palubní desku. Zjistěte zobrazený zdravotní stav spolu s hlášeními hráčů, aktuální výkonnost, používání paměti a otevřené incidenty.

Nízší skóre znamená, že server potřebuje pozornost; sám o sobě neidentifikuje chybu.

Některé měření nejsou k dispozici na starších verze serverů. Zkontrolujte konzol a použijte podporované výkonné nástroje serveru, pokud budete potřebovat více detailů.

Pro aktivní problém sledujte [vyšetřovat incident](incident-investigation.md).
