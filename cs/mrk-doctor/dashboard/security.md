# Bezpečnost palubního desku

- Sdílejte přístup pouze s důvěryhodnými správci.
- Použijte HTTPS pro webovou palubní desku a zabezpečí připojení k jejím službám.
- Udržujte domnělý místní spojení, když služby běží na stejném hostitu.
- Chránit přidělené příspěvky pomocí firewalu a proxy pravidel.
- Pokud je token vystaven, otočte ho `/doctor dashboard setup` .
- Předtím, než je pošlete někomu, zkontrolujte zprávy a screenshoty.

Nikdy nevložte token do palubního desku do veřejného problému, kanálu Discord nebo příkladu konfigurace. Pokud nepotřebujete přístup k webu, deaktivujte `doctor.dashboard.enabled` a restartujte.
