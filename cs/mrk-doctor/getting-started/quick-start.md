# Rychlý start

1. Způsob `/doctor status` pro kontrolu stavu serveru.
2. V hře běžte `/doctor` , abyste otevřeli přehled.
3. Způsob `/doctor incidents` pro otevřené problémy.
4. Vypravte `/doctor changes` , abyste zkoumali nedávné změny.
5. Použijte `/doctor report` , pokud potřebujete zprávu o podpoře.

První čtení může trvat po spuštění.

Pro přístup k webu postupujte po nastavení palubního desku [dashboard setup](../dashboard/initial-setup.md). Pro problém, který již postihuje hráče, otevřete [vyřešení problémů](../support/troubleshooting.md).
