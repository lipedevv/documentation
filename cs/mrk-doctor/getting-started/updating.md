# Aktualizace

1. Záloha serveru a kompletní složku `plugins/MRKDoctor/` .
2. Zastavte server normálně.
3. Změňte staré JAR novým vydáním stejného vydání.
4. Přezkoumejte poznámky o propuštění a porovnejte poskytnutou konfiguraci s stávajícími nastavením.
5. Začněte server a zkontrolujte `/doctor status`, palubní desku a konzol.

{% hint style="warning" %}
Diagnostický snímek není záloha. Nepředpokládejte, že chybějící konfigurační možnosti budou automaticky přidány k stávajícímu souboru.
{% endhint %}
