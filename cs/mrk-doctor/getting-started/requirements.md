# Požadavky

Univerzální edice se zaměřuje na servery kompatibilní s Bukkitem od Minecraft **1.8.9 až 26.2**. Použijte verzi Java požadovanou serverovým softwarem. Zachovávejte server a instalaci Java podporované jejich příslušnými dodavateli.

Optimalizované vydání Paper je samostatnou verzí pro **Paper 1.21.x s Java 21**. Není to verze pro staré servery nebo Paper 26.2.

{% hint style="warning" %}
Nikdy neinstalujte univerzální a optimalizované papírové vydání spolu, nebo chráněné i neochráněné kopie.
{% endhint %}

Žádný další plugin není povinný. Nechme dostatek volného prostoru na disku pro diagnostickou historii a exportované zprávy.

Některé měření nemusí být k dispozici na každé verzi serveru.

The web dashboard is embedded in the plugin JAR. Remote access requires one suitable hosting allocation and a secure web address or reverse proxy. See [dashboard setup](../dashboard/initial-setup.md).
