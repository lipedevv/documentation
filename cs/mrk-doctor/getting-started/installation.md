<a id="installation"></a>
# Instalace

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Vyberte si složku
Použijte univerzální JAR, pokud konkrétně nepotřebujete optimalizované Papírové vydání.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Zastav a odstoupni.
Zastavte server Minecraft normálně a před přidáním doplňku si vytvořte zálohu.
{% endstep %}
{% step %}
<a id="install"></a>
#### Instalace
Umístěte jednu MRK Doctor JAR do složky `plugins/` ve vašem serveru a odstraníte starší kopie z této složky.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Začněte a zkontrolujte
Započítat server. Potvrdit, že nejsou žádné chyby při spuštění MRK Doctor, pak spuštění `/doctor status` jako provozovatel nebo z konzole.
{% endstep %}
{% endstepper %}

Pokračujte v [rychlý start](quick-start.md). Použijte pluginy hot-loaderů k instalaci nebo nahrazení MRK Doctor.
