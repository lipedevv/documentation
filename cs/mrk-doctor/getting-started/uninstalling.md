# Odinstalování

Zastavte server a pak odstraníte MRK Doctor JAR z `plugins/`.

Udržujte `plugins/MRKDoctor/` , pokud můžete znovu nainstalovat nebo potřebovat svou stávající historii a zprávy. Chcete-li odstranit i tyto údaje, nejdříve archivujte složku a vymažte ji až po ověření zálohovacího zálohování.

Odstraňte veškeré směry reverzního proxy nebo přidělení hostingu, které odhalily vestavěnou palubní desku MRK Doctor.
