# Перевірте стан сервера

Запустити `/doctor status` або відкрити панель панелі. Перегляньте відображений стан здоров'я разом з звітами гравців, поточною продуктивності, використанням пам'яті та відкритими інцидентами.

Понижний показник означає, що сервер потребує уваги; він не ідентифікує винний плагин сам по собі. Сравніть читання з часом, а не зробити висновок з одного моменту.

Деякі вимірювання недоступні на старіх версіях сервера. Перевірте консоль і використовуйте підтримувані інструменти виконання сервера, якщо потрібно більше деталей.

Для активної проблеми, слідкуйте за [розслідувати інцидент](incident-investigation.md).
