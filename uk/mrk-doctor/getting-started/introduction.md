# Вітаємо вас

MRK Doctor допомагає адміністраторам сервера досліджувати відставання, помилки плагінів та несподівані зміни.

Ви можете переглянути стан сервера, перевірити інциденти, переглянути останні зміни, перевірити дозвіл гравця і генерувати діагностичні звіти.

Почніть з установки [installation](installation.md), а потім слідуйте за [швидкий старт](quick-start.md).

{% hint style="info" %}
Подозрювана причина є підстави для розслідування, а не доказ того, що плагин випав.
{% endhint %}
