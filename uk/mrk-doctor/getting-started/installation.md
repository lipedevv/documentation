<a id="installation"></a>
# Інсталяція

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Виберіть свій файл
Використовуйте універсальний JAR, якщо вам не потрібен оптимізований паперовий випуск.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Стоп і відступить
Припиніть сервер Minecraft нормально і зробіть резервне завантаження перед додаванням плагіну.
{% endstep %}
{% step %}
<a id="install"></a>
#### Установка
Розкладіть одну MRK Doctor JAR в папку `plugins/` сервера.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Почнете і перевіріть
Почнете сервер. Поверніть, що немає помилок завантаження MRK Doctor, а потім запустите `/doctor status` як оператор або з консолі.
{% endstep %}
{% endstepper %}

Продовжуйте з [швидкий старт](quick-start.md). Не використовуйте плагин-горячі завантажувачі для установки або заміни MRK Doctor.
