# Замоги

Всесвітнє видання спрямоване на сервери, які відповідають за Bukkit, від Minecraft **1.8.9 до 26.2**. Використовуйте версію Java, необхідну для вашого сервера.

Оптимізовано Paper Edition є окремою версією для **Paper 1.21.x з Java 21**. Це не є версією для старих серверів або Paper 26.2.

{% hint style="warning" %}
Не встановлюйте Universal і оптимізовані паперові видання разом, або як захищені, так і незахищені копії.
{% endhint %}

Не обов'язкова додаткова плагинка. Оставте достатньо свободного дискового простору для діагностичної історії та експортованих звітів.

Деякі вимірювання можуть бути недоступні на всіх версіях сервера.

The web dashboard is embedded in the plugin JAR. Remote access requires one suitable hosting allocation and a secure web address or reverse proxy. See [dashboard setup](../dashboard/initial-setup.md).
