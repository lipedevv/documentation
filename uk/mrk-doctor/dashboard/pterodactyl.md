# Pterodactyl hosting

Виберіть одну доступну ассигновацію в панелі сервера, наприклад `7854`, і встановити `doctor.dashboard.port` на цей порт.

Використовуйте адресу bind, необхідну для вашої мережі хостингу. Адреса локального хости контейнера не доступна з окремого контейнера. Якщо ваш хост вимагає `0.0.0.0`, переконайтеся, що розподіл захищений його брандмауїлом або безпечним прокси перед тим, як дозволити доступ.

Веб-паратура обслуговується безпосередньо плагіном. Прослідуйте початкову настройку [initial setup](initial-setup.md), запустить знову після зміни адреси зв'язку або порту і перевіріть сторінку за допомогою присвоєного адресу.

{% hint style="warning" %}
Не відкривайте необмежені порти для вирішення проблеми з підключенням. Якщо ваш план не дозволяє вибрати або викласти виділення, тільки провайдер хостингу може зробити доступний порт прихідної панелі панелі; плагин не може обгортати брандмауэр хостингу.
{% endhint %}
