# Зберігайте діагностичний хвіст

Запустити `/doctor snapshot`. Наказна повідомляє про шлях генерованого файлу в `plugins/MRKDoctor/snapshots/`.

Зберігайте фото, коли вивчаєте проблему або перед зміною конфігурації плагіну. Перегляньте його для конфігурації конфіденційної інформації перед тим, як поділитися нею.

{% hint style="warning" %}
Снуп-шот - це діагностичний запис, а не серверна копія. Він не може відновлювати світи, файли плагінів, конфігурацію або повну папку даних MRK Doctor.
{% endhint %}
