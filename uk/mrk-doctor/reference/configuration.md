# Посібник конфігурації

Ця посилання охоплює `plugins/MRKDoctor/config.yml` в універсальному виданні. Відзавантажити після редагування, якщо ви не перевірили поведінку перевантаження настройки.

| Накладення | Позадумовно | Мета |
| --- | --- | --- |
| `doctor.server-id` | `standalone` | Лейбл використовувався для цього сервера. |
| `doctor.performance.healthy-sample-seconds` | `15` | Інтэрвал моніторингу під час нормальної роботи. |
| `doctor.performance.incident-sample-seconds` | `5` | Інтенвіаль моніторингу під час інциденту. |
| `doctor.changes.enabled` | `true` | Обов'язково відстежувати останні зміни. |
| `doctor.changes.interval-seconds` | `30` | Перевірка змін; використовуйте не менше 10 секунд. |
| `doctor.changes.max-file-bytes` | `1048576` | Ограничення розміру для детальних порівнянь текстових файлів. |
| `doctor.dashboard.enabled` | `true` | Знайдіть підключення до панелі. |
| `doctor.dashboard.bind` | `0.0.0.0` | Слухайте на розподіл сервера. Використовуйте `127.0.0.1` , коли доступ повинен проходити через реверс-прокси одного хостова. |
| `doctor.dashboard.port` | `7854` | Одиничний порт, який використовується вбудованою панелью панелі та її аутентифікованим API. |
| `doctor.dashboard.cors-origin` | `http://127.0.0.1:7854` | Факультативне дозволене походження для передових розподілів прокси; доступ з одного походження не вимагає окремого адресу фронт-энд. |
| `doctor.dashboard.token-hash` | Попусте | Управляється `/doctor dashboard setup`; не редагуйте ручно. |
| `storage.raw-retention-hours` | `24` | Период зберігання для детальної метричної історії. |
| `logging.debug` | `false` | Покіньте на замовчуванням; він не дозволяє додаткового реєстрації в цьому випуску. |

Використовуйте позитивні інтервалу моніторингу та дійсний порт панелі панелі. Зниження інтервалів збільшує роботу моніторингу; спочатку тестування змін на сервері стажування.

{% hint style="warning" %}
Не вставляйте токен панелі в приклади конфігурації.
{% endhint %}
