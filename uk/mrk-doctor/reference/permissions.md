# Дозволи

Всі дозволи MRK Doctor дефолтом для операторів. `mrkdoctor.view` необхідна для кожної команди, включаючи ті, які мають додаткове дозволення.

| Дозвол | Доступ |
| --- | --- |
| `mrkdoctor.view` | Диагностика, перелік інцидентів і змін, створення мгновенних знімків і проведення перевірок дозволів/командувань. |
| `mrkdoctor.report` | Створюйте звіти. |
| `mrkdoctor.dashboard` | Погляньте деталі підключення до панелі панелі та замінити її акредитив. |
| `mrkdoctor.admin` | Адміністративний доступ, включаючи перезавантаження та вищезгадані дозволи. |

{% hint style="warning" %}
Не надавайте діагностичні дозволи звичайним гравцям.
{% endhint %}

Зрезервовані вузли `mrkdoctor.trace`, `mrkdoctor.rollback`і `mrkdoctor.update` не розблокують відстеження, повернення або автоматичні оновлення в цьому випуску.
