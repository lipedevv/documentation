# Переглянути останні зміни

Run `/doctor changes` or use the dashboard to review available plugin and configuration changes. `/doctor timeline` currently shows the same recent-change list in the Universal edition.

Поверніть часові марки з повідомленою проблемою. Зміна, що відбувається біля інциденту, є корисним контекстом, але не доводить, що це викликало проблему.

MRK Doctor не спостерігає кожен файл або замінює зовнішню систему резервного копию. Щоб скасувати зміну, зупини сервер і слідуй за підтримкою постачальника плагінів за допомогою власного резервного копию.

Зміни відстеження можна включити або відключити в конфігурації [configuration](../configuration/overview.md).
