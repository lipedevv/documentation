# Crear y compartir un informe

Ejecutar `/doctor report` como operador o miembro del personal con `mrkdoctor.report`. Espera el mensaje de finalización y abra el archivo reportado de `plugins/MRKDoctor/reports/`.

La edición Universal produce un informe HTML que se puede abrir en un navegador.

Antes de compartir:

1. Lea el informe completo y elimine la información no relacionada.
2. Busque credenciales, direcciones privadas, rutas de archivos, detalles del jugador y valores confidenciales de configuración.
3. Compartir sólo la información necesaria para investigar el asunto.
4. Utilice un destino de apoyo verificado.

{% hint style="danger" %}
El enmascaramiento automático no garantiza que un informe no contenga secretos. Siempre revise usted mismo.
{% endhint %}

Include your Minecraft version, MRK Doctor version, a short description, reproduction steps, and the time the problem occurred. See [support](../../support.md).
