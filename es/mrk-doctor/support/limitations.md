# Disponibilidad y limitaciones

- El médico de MRK proporciona orientación diagnóstica, no una identificación de causa raíz garantizada.
- No actualiza automáticamente los plugins, repara archivos, restaura copias de seguridad o devuelve cambios.
- Las instantáneas son registros diagnósticos, no copias de seguridad restaurables del servidor.
- El seguimiento detallado del oyente y el seguimiento de tareas lentas no están disponibles en este lanzamiento.
- Algunas medidas y características varían según la versión del servidor y la edición.
- El seguimiento de cambios recientes no cubre todos los archivos del servidor.
- El acceso remoto al panel de control sigue dependiendo de un puerto asignado accesible o de un proxy inverso suministrado por el servidor host.
- El enmascaramiento automático no puede garantizar que un informe esté libre de información sensible.

En caso de que no se resuelva el problema, el soporte de contacto de [contact support](../../support.md) deberá presentar un informe revisado y una descripción clara.
