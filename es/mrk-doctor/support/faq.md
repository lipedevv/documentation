# FAQ

<a id="does-mrk-doctor-fix-problems-automatically"></a>
## ¿El Doctor de la RMC arregla los problemas automáticamente?

No, proporciona diagnóstico para ayudarle a elegir un siguiente paso seguro.

<a id="is-a-suspected-plugin-definitely-responsible"></a>
## ¿Es un plugin sospechoso definitivamente responsable?

No. Verifique el problema antes de culpar, eliminar o reemplazar un complemento.

<a id="can-i-use-the-dashboard-immediately-after-copying-the-jar"></a>
## ¿Puedo usar el panel inmediatamente después de copiar el JAR?

Sí. La aplicación del panel de instrumentos está integrada en el plugin JAR. Generar un token, configurar un puerto accesible, y seguir la configuración de conexión [connection setup](../dashboard/initial-setup.md).

<a id="is-a-diagnostic-snapshot-a-backup"></a>
## ¿Una instantánea de diagnóstico es una copia de seguridad?

No, mantenga copias de seguridad separadas de mundos, archivos de complementos, configuración y datos.

<a id="should-i-install-both-editions-or-both-protection-variants"></a>
## ¿Debería instalar ambas ediciones o ambas variantes de protección?

No, sólo instale una JAR compatible.

<a id="can-i-share-reports-without-reviewing-them"></a>
## ¿Puedo compartir informes sin revisarlos?

Siempre compruebe información sensible, incluso cuando se ha aplicado un enmascaramiento automático.
