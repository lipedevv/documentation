# Revisar los cambios recientes

Ejecutar `/doctor changes` o utilizar el panel de control para revisar los cambios de configuración y de complemento disponibles. `/doctor timeline` muestra actualmente la misma lista de cambios recientes en la edición Universal.

Comparar las temporadas con el problema reportado.Un cambio que ocurre cerca de un incidente es un contexto útil, pero no prueba que causó el problema.

MRK Doctor no vigila todos los archivos o reemplaza un sistema de copia de seguridad externo. Para deshacer un cambio, detenga el servidor y siga el procedimiento de recuperación soportado por el proveedor de plugins afectados utilizando su propia copia de seguridad.

El seguimiento de cambios puede activarse o desactivarse en la configuración [configuration](../configuration/overview.md).
