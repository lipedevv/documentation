# Actualización

1. Haga copia de seguridad del servidor y la carpeta completa de `plugins/MRKDoctor/` .
2. Detenga el servidor normalmente.
3. Replace el viejo JAR con el nuevo lanzamiento de la misma edición.
4. Revise las notas de liberación y compare la configuración suministrada con sus configuraciones existentes.
5. Inicie el servidor y compruebe `/doctor status`, el panel y la consola.

{% hint style="warning" %}
Una instantánea de diagnóstico no es una copia de seguridad. No asuma que las opciones de configuración faltantes se agregarán automáticamente a un archivo existente.
{% endhint %}
