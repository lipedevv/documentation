# Bienvenido .

MRK Doctor ayuda a los administradores de servidores a investigar el retraso, errores de plugins y cambios inesperados.

Puede ver el estado del servidor, inspeccionar incidentes, revisar cambios recientes, verificar los permisos de los jugadores y generar informes de diagnóstico.

Comience con la instalación de [installation](installation.md), luego siga el inicio rápido de [quick start](quick-start.md).

{% hint style="info" %}
Una causa sospechosa es una pista para investigar, no una prueba de que un plugin es culpable.
{% endhint %}
