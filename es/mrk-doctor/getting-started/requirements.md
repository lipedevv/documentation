# Requisitos

La edición Universal se dirige a servidores compatibles con Bukkit desde Minecraft **1.8.9 hasta 26.2**. Utilice la versión Java requerida por su software de servidor. Mantenga su servidor e instalación Java apoyados por sus respectivos proveedores.

La edición optimizada de Paper es una versión separada para **Paper 1.21.x con Java 21**. No es la versión para servidores heredados o Paper 26.2.

{% hint style="warning" %}
Nunca instale las ediciones Universal y Optimized Paper juntos, o las copias protegidas y no protegidas.
{% endhint %}

No hay complemento adicional obligatorio. Deja suficiente espacio libre en el disco para el historial de diagnóstico y los informes exportados.

Algunas mediciones pueden no estar disponibles en todas las versiones del servidor.

El panel de control web está incorporado en el plugin JAR. El acceso remoto requiere una asignación de alojamiento adecuada y una dirección web segura o proxy inverso. Ver [configuración del panel de control](../dashboard/initial-setup.md).
