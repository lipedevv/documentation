<a id="installation"></a>
# Instalación

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Elige tu archivo
Utilice el JAR Universal a menos que necesite específicamente la edición de papel optimizada.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Deténgase y retroceda .
Detenga el servidor Minecraft normalmente y haga una copia de seguridad antes de agregar el plugin.
{% endstep %}
{% step %}
<a id="install"></a>
#### Instalar
Coloque un MRK Doctor JAR en la carpeta `plugins/` de su servidor.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Comienza y comprueba
Inicie el servidor. Confirme que no hay errores de inicio de MRK Doctor, luego ejecute `/doctor status` como operador o desde la consola. Permita tiempo para las mediciones iniciales.
{% endstep %}
{% endstepper %}

Continúa con [inicio rápido](quick-start.md). No utilice los cargadores de plugins para instalar o reemplazar MRK Doctor.
