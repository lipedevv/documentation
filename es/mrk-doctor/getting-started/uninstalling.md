# Desinstalación

Detenga el servidor, y luego eliminen el MRK Doctor JAR de `plugins/`.

Mantenga `plugins/MRKDoctor/` si reinstala o necesita su historial y informes existentes. Para eliminar esos datos también, archiva la carpeta primero y sólo la borra después de verificar la copia de seguridad.

Elimine cualquier ruta de proxy inverso o asignación de alojamiento que expusiera el panel de control de MRK Doctor incorporado.
