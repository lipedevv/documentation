# Inicio rápido

1. Ejecutar `/doctor status` para comprobar el estado actual del servidor.
2. En el juego, ejecuta `/doctor` para abrir la visión general.
3. Ejecutar `/doctor incidents` para ver los problemas abiertos.
4. Ejecutar `/doctor changes` para revisar los cambios recientes rastreados.
5. Utilice `/doctor report` cuando necesite un informe de apoyo.

Las primeras lecturas pueden tardar un poco después de la puesta en marcha. Mantenga el servidor en funcionamiento antes de juzgar una nueva instalación.

Para acceder a la web, siga la configuración del panel de control [dashboard setup](../dashboard/initial-setup.md). Para un problema que ya afecta a los jugadores, abra [solucionando problemas](../support/troubleshooting.md).
