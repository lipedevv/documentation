# Guardar una instantánea de diagnóstico

Ejecutar `/doctor snapshot`. El comando informa la ruta del archivo generado en `plugins/MRKDoctor/snapshots/`.

Mantenga una instantánea cuando investigue un problema o antes de cambiar la configuración de un plugin.

{% hint style="warning" %}
Una instantánea es un registro de diagnóstico, no una copia de seguridad del servidor. No puede restaurar mundos, archivos de complementos, configuración o la carpeta completa de datos de MRK Doctor. Mantenga copias de seguridad separadas.
{% endhint %}
