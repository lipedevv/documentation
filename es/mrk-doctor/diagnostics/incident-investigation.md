# Investigar un problema

1. Confirme lo que los jugadores están experimentando y note cuándo comenzó.
2. Ejecutar `/doctor status` y `/doctor incidents`.
3. Abre el incidente en el panel de control y lee sus detalles disponibles y las sugerencias de verificación.
4. Compare el tiempo con los cambios recientes [recent changes](../changes/change-tracker.md).
5. Lea los errores de consola relevantes y compruebe la propia documentación del plugin afectado.
6. Guarde un informe [report](../reports/creating-reports.md) antes de cambiar el servidor.
7. Retroceda, haga un cambio reversible y observa el resultado.

{% hint style="warning" %}
Tratar un plugin sospechoso y cualquier indicación de confianza como una guía de investigación, no una garantía. MRK Doctor no realiza reparaciones, actualizaciones de plugin o retroceso para usted.
{% endhint %}
