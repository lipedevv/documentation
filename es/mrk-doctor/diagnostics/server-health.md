# Verifique el estado del servidor

Ejecutar `/doctor status` o abrir el panel. Revise el estado de salud mostrado junto con los informes de jugadores, el rendimiento actual, el uso de memoria e incidentes abiertos.

Una puntuación más baja significa que el servidor necesita atención; no identifica un plugin culpable por sí solo. Compara las lecturas a lo largo del tiempo en lugar de sacar una conclusión de un momento.

Algunas mediciones no están disponibles en versiones anteriores del servidor.

Para un problema activo, siga [investigar un incidente](incident-investigation.md).
