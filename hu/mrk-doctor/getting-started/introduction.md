# Üdvözlöm!

Az MRK Doctor segít a szerver- adminisztrátorok kutatásában a késleltetés, a plugin hibák és a váratlan változások.

A rendszerben a szerver állapotát láthatja, megvizsgálja az eseteket, áttekintheti a legutóbbi változásokat, ellenőrizheti a játékos engedélyét és diagnosztikai jelentéseket készíthet.

Kezdjük az [telepítéssel](installation.md), majd kövessük az [gyorsstartot](quick-start.md).

{% hint style="info" %}
A gyanús ok a nyomozás útmutatója, nem a plugin hibásának bizonyítása.
{% endhint %}
