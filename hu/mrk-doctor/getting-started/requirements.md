# Feltételek

The Universal edition targets Bukkit-compatible servers from Minecraft **1.8.9 through 26.2**. Use the Java version required by your server software. Keep your server and Java installation supported by their respective vendors.

A Papers- kiadás az **Paper 1.21.x-nek Java 21**-el külön építkeztetett. Nem a legacy szerverekhez vagy a Paper 26.2-hez készült.

{% hint style="warning" %}
Soha ne telepítsd össze az egyetemes és az optimalizált papír kiadásokat, vagy mind a védett, mind a védetlen példányokat.
{% endhint %}

Nincs szükség további plugin-re. Adjon elegendő szabad felületet a diagnosztikai történelemre és exportált jelentésekre.

Néhány mérés nem áll rendelkezésre minden szerverververzióban.

A webes műszerpult a JAR pluginbe van beépítve. A távoli hozzáféréshez egy megfelelő tárolóosztás és egy biztonságos webcím vagy visszaforduló proxy szükséges. Lásd [műszerpult beállítása](../dashboard/initial-setup.md).
