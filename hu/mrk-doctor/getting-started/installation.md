<a id="installation"></a>
# Feltöltés

{% stepper %}
{% step %}
<a id="choose-your-file"></a>
#### Válassza ki a fájlt
A védett és a védetlen JAR-ok ugyanazon a kiadás alternatív építései.
{% endstep %}
{% step %}
<a id="stop-and-back-up"></a>
#### Állj le és hátrálj!
Hagyja abba a Minecraft szervert normálisan, és készítsen egy biztonsági mentést, mielőtt hozzáadná a plugin-t.
{% endstep %}
{% step %}
<a id="install"></a>
#### Feltöltés
Tedd egy MRK Doctor JAR-t a szervered `plugins/` mappájába, és távolítsd el az idősebb másolatokat.
{% endstep %}
{% step %}
<a id="start-and-check"></a>
#### Kezdjük és ellenőrizzük
Indítsa be a szervert. Ellenőrizze, hogy nincs MRK Doctor indítási hibája, majd futtassa be az `/doctor status` -t operátorként vagy a konzoltól. Adjon időt az első mérésekre.
{% endstep %}
{% endstepper %}

Folytassa a [gyorsstart](quick-start.md). Ne használja a plugin meleg töltőket, hogy telepítse vagy cserélje MRK Doctorot.
