# Az elmúlt változások felülvizsgálata

Run `/doctor changes` or use the dashboard to review available plugin and configuration changes. `/doctor timeline` currently shows the same recent-change list in the Universal edition.

A jelentett problémahoz hasonló időcímkék összehasonlítása hasznos összefüggés, de nem bizonyítja, hogy ez okozta a problémát.

Az MRK Doctor nem néz minden fájlt, vagy nem helyettesíti a külső biztonsági mentő rendszert.

A változások nyomon követését az [konfigurációban](../configuration/overview.md)be lehet engedélyezni vagy le lehet állítani .
